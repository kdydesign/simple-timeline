# WorkRail 앱 아이콘

흰색 수평 획과 하늘색 사선 획은 하나의 심벌이다. 256px 격자에서 심벌 중심 (128, 129.25)을 고정하고 두 획의 가로와 세로를 각각 92%로 줄였다. 심벌의 폭은 222px에서 204.24px가 되며 타일의 모서리 반경은 31px다. 16px 격자의 소형 도안은 작은 크기에서도 획 사이가 구분되도록 간격을 따로 조정했다. [일반 원본](icon.svg) · [소형 원본](icon-small.svg)

PNG는 일반 원본을 256px로 렌더링했다. Windows ICO의 16·20px 프레임은 기존 소형 도안을 사용하고, 24·32·40·48·64·128·256px 프레임은 조정한 일반 원본을 각 크기로 렌더링했다. 렌더링에는 Inkscape, ICO 생성에는 ImageMagick을 사용했다. [PNG](icon.png) · [Windows ICO](icon.ico)

Windows 창·트레이·실행 파일·설치 프로그램은 같은 ICO를 사용한다. 시작 메뉴 바로가기와 작업 표시줄 재실행 항목은 설치 폴더의 ICO를 참조하며 파일 이름에 ICO의 SHA-256을 포함한다. 이전 모노그램 시안은 별도로 보존한다. [이전 시안](workrail-wr-source.png)
