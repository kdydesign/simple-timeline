# 프로젝트 설정 인수인계 — Codex 하네스

## 사용자 요청

본 프로젝트는 Codex 프로젝트로 하네스 엔지니어링을 기반으로 진행한다.
스테이지 1 이전에 프로젝트 설정을 먼저 진행한다.

## 결과와 범위

- 루트 AGENTS.md를 짧은 진입 안내로 만들고 기존 설계·지도·상태에 연결했다.
- 새 채팅 시작·수행·종료 절차와 로컬 Markdown 트래커 규칙을 연결했다.
- Node.js 기본 기능으로 문서·단계 계약을 검사하는 하네스를 추가했다.
- 누락 문서·깨진 링크·잘못된 단계 의존·완료 인수인계 누락은 검사 실패가 된다.
- 검사 결과는 지금 착수 가능한 단계가 01-domain임을 보여준다.
- Ubuntu·Windows GitHub Actions 워크플로와 텍스트·생성물 제외 설정을 추가했다.
- 앱 스캐폴딩·의존성·DB·앱 테스트·설치 파일은 추가하지 않았다.
- 사용자 계정의 Codex UI 프로젝트 생성·재사용 환경 등록은 수행하지 않았다.

## 검증 근거

최초 8개 회귀 사례의 실패와 구현 후 통과를 확인했다.
별도 코드 검토에서 발견한 중복 상태 행·코드 예시의 메타데이터 덮어쓰기·따옴표 링크 누락에
회귀 사례 3개를 추가해 실패를 재현하고 수정했다. 총 11개가 통과했다.
사례는 필수 문서·실제 상대 링크·미존재 선행 단계·순환 의존·차단 단계 착수·완료 인수인계·잘못된 상태도 다룬다.
전체 저장소 체커와 Node 테스트, git diff 검사도 통과했다.
빈 임시 디렉터리에 대한 CLI 검사는 종료 코드 1과 누락 파일 안내를 확인했고 디렉터리를 변경하지 않았다.
워크플로 YAML도 파싱했다. 상세 테스트 출력이 필요하면 Node 테스트 명령에 `--test-isolation=none`을 추가한다.
로컬 검증과 원격 CI 성공은 구분한다. 실제 원격 결과와 최종 커밋은 종료 메시지에서 전달한다.
Windows 앱 설치·실행 검증은 아직 수행하지 않았다.
