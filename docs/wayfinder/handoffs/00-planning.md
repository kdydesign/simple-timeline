# 스테이지 0 인수인계 — 전체 설계와 진행 지도

- 상태: 문서 작성 및 검토. 스테이지 1은 미착수.
- 기준 브랜치: main. 시작 시 저장소에 커밋·앱 코드가 없었다.
- 원격 반영: 채팅 종료 시 전달하는 최종 커밋과 GitHub 문서 링크로 확인한다.

## 사용자가 확정한 사항

Electron + React + SQLite, 오프라인 Windows 설치형 우선, 공유 없음,
참여자는 이름 목록, Teams는 낮은 우선순위의 후속 작업, 모바일 제외.
간트는 전체 일정이 걸쳐 있는 월들을 표시하고 달력은 월별이다.
새 채팅을 순차적으로 만들어 스테이지별로 진행한다.

- `docs/wayfinder/STATUS.md`: 현재 상태.

## 에이전트 제안과 미결정 사항

7개 후속 스테이지의 분할은 이번 문서의 제안이다.
main/preload/renderer 경계, 날짜 계산 규칙·DB 드라이버·화면 모양 등은
확정된 요구사항과 구분하여 전체 설계에 명시했다. 각 담당 단계에서 확정한다.
설계 초안 작성은 모든 세부 설계의 사용자 승인을 뜻하지 않는다.
현재는 제품 코드·의존성·테스트·Windows 설치 파일이 없다.
