# Windows 배포 정책

사용자는 이번 채팅 Q1~Q3에 다음을 선택했다. 기존 도메인·저장·화면 승인을 변경하지 않는다.

- 대상: Windows 11 x64. Windows Server CI는 자동 검증 환경이며 Windows 11 실기 확인을 대신하지 않는다.
- 설치: 현재 사용자용 NSIS. 관리자 권한을 요구하지 않는다. 고정 appId는 `com.kdydesign.simpletimeline`이다.
- 데이터: 사용자 AppData의 `SimpleTimeline/data/timeline.sqlite3`. 업데이트·재설치와 제거 후에도 보존한다.
- 서명·배포: 서명 없이 비공개 GitHub Actions 산출물로 제공한다. 공개 GitHub Release를 만들지 않는다.
  알 수 없는 게시자/SmartScreen 경고 가능성을 안내했다. 자동 업데이트·원격 업데이트 확인은 추가하지 않는다.

MVP 구현 당시 에이전트의 구체화: one-click의 사용자별 설치를 사용해 전체 사용자 선택 화면을 만들지 않는다.
설치 직후 자동 실행은 끈다. 기본 설치 위치는 사용자 로컬 AppData의 Programs 아래이며,
설치 파일·앱 버전·CPU·소스 SHA·설치 파일 SHA256을 산출물에 기록한다.
실행하지 않은 검증을 통과로 표시하지 않는다. 실제 사용자 인수와 이후 범위 조정은 아래 기록을 따른다.

2026-11-04 승인된 [후속 개선 설계](../design/post-mvp-improvements.md)는 완료 화면과
기본 체크된 실행 옵션·마침 버튼을 추가해 위 one-click·설치 후 실행 끔 결정을 대체한다.
전용 아이콘은 사용자 선택 B를 적용한다. `oneClick: false`, `runAfterFinish: true`,
`allowElevation: false`로 사용자별 완료 화면을 구성했으며,
사용자별 설치·DB 보존·서명·배포 정책은 유지한다.

CI의 방화벽 검증은 격리된 VM의 관리자 권한을 쓴다. 사용자 앱/설치본의 관리자 권한 요구와 구분한다.
Windows 11 수동 업데이트 확인에는 UPDATE-TEST-ONLY 비공개 fixture를 별도로 제공할 수 있다. 정식 배포본과 혼동하지 않도록 이름·manifest에 표시한다.

2026-11-04 사용자는 기본 설치·실행·업데이트·제거·재설치 및 데이터 보존을 확인하고,
상세 개선·오류 검증은 별도 후속 작업으로 분리했다. 이번 MVP는 이 인수 범위로 마무리한다.
이는 오프라인 요구나 저장 정책의 변경이 아니다. 미확인 항목과 관측의 경계는 [사용자 인수 기록](user-acceptance.md)을 따른다.

## Planrail 후속 변경 (0.3.0)

[Planrail 승인 설계](../design/planrail-improvements.md)에 따라 표시명·실행 파일·설치 파일·바로가기는 Planrail이다.
기존 사용자 데이터와 설정을 이어 쓰기 위해 내부 package/appId·프로필·설정 키는 유지한다.
새 기본 설치 위치는 `%LOCALAPPDATA%\Programs\Planrail`, 기존 설치는 이전 위치를 재사용한다.
표준 폴더 선택 화면을 제공하되 선택한 경로 뒤에 제품명을 강제로 덧붙이지 않는다.
사용자별 설치·비승격·완료 후 기본 체크 실행·제거 후 DB 보존 정책은 그대로다.

CI는 고정된 실제0.2.1 소스를 별도 worktree에서 빌드해 이름 변경 업그레이드를 검증하고,
현재 버전의 가상 다음 버전 업데이트도 별도로 검사한다. 실행 결과는 [Planrail 구현 기록](../implementation/2026-11-05-planrail.md)을 따른다.
대화형 폴더 선택·권한 거부·Windows11 트레이/배율 확인은 silent 설치 CI와 구분한다.
설치/제거 전 트레이의 ‘종료’를 사용한다. 창 X는 숨김이므로 실제 종료와 다르다.

## LAN 공유 후속 (0.6.0)

선택적인 [사내 LAN 공유](../design/lan-project-sharing.md)를 추가한다. 외부 서버·클라우드 로그인·자동 실행은 제공하지 않는다.
개인 일정의 오프라인 사용·설치 정체성·서명/비공개 배포·데이터 보존 정책은 유지한다.
X/Alt+F4는0.5.0부터 숨김/완전 종료/취소를 선택하며, 설치/제거 전 트레이의 현재 문구 `Exit`로 완전히 종료한다.
0.6.0 schema v3로 업그레이드한 DB를 구버전 앱으로 여는 것은 지원하지 않는다.
[사용 안내](user-guide.md)는 선택 포트/회사 방화벽 설정과 실제 Windows·LAN 인수 한계를 설명한다.
