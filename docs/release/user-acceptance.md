# MVP 설치 인수 기록 — 2026-11-04

사용자가 이 채팅에서 직접 전달한 결과다. 에이전트가 사용자 PC에서 재실행하거나 로그로 측정한 결과가 아니다.
대상 정책은 Windows 11 x64이며, 정확한 Windows 빌드·계정 종류·네트워크 차단 여부는 이번 보고에 포함되지 않았다.
해당 세부 정보를 추정하지 않는다.

`036ee001e664904eaf964677798451d9c52f6b57` 설치본 0.1.0과 검증용 0.1.1이다.
정확한 파일명·exe SHA256·다운로드와 CI 결과는 그 문서에 고정했다.
0.1.1은 같은 소스·같은 DB schema에서 버전만 올린 업데이트 fixture다. 새로운 기능이나 schema migration 검증이 아니다.
사용자 보고의 데이터 보존은 UI 관측이며 DB ID·경로·원본 파일 해시의 별도 실측으로 확대하지 않는다.

## 사용자가 조정한 이번 MVP의 인수 범위

사용자는 “현재는 mvp 이고 기본적이 설치 실행 제거와 관련된 검증만 진행했어.
상세한 개선및 오류 사항은 별도로 진행할꺼야”라고 밝혔다.
이에 따라 기본 설치·실행·업데이트·제거·재설치와 데이터 보존 확인을 이번 MVP의 사용자 인수 범위로 삼아
스테이지 7과 현재 MVP 지도를 마무리한다. 추가 검증을 완료로 가정한 결정이 아니다.
앱의 오프라인·도메인·날짜·저장 요구사항이나 구현을 변경하지 않는다.

## 별도로 진행할 상세 검증·개선

다음 항목은 이번 사용자 보고에서 확인하지 않았으며 MVP 인수의 차단 조건에서 후속 작업으로 옮겼다.

- 사용자 PC의 네트워크 차단 상태에서 최초 설치·최초 실행·새 데이터 생성·핫픽스 CRUD·두 모드 전체 시나리오.
- Windows 정확한 빌드·표준 계정/관리자 계정 구분·다른 사용자에 대한 영향·DB ID/경로/파일 해시 직접 비교.
- 실제 Windows 100%/200% 배율, 키보드 전체 동선, Narrator.
- 격리된 Windows 환경의 잠금·ACL/권한·용량 부족·강제 종료·손상·고버전·migration 실패.
- 상세 사용성 개선과 발견되는 오류의 재현·수정. 기존 [실기 양식](manual-checklist.md)을 후속 기록에 사용할 수 있다.

오프라인 수정·삭제·재실행과 업데이트·제거/재설치 보존에 대한 Windows Server CI 증거는 유지한다.
그 결과를 Windows 11 사용자 PC의 오프라인 전체 시나리오 통과로 옮겨 적지 않는다.
기존 간트 gutter·migration 사본 로그·빌드 도구 advisory와 CI 방화벽 cleanup 진단 보완은
[실행 기록](../implementation/stage-07.md)의 보류 사항을 따른다.
후속 작업은 새 요청에서 범위를 정하며 이번 기록으로 구현을 시작하지 않는다.
