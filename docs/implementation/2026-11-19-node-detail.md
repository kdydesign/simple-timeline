# NodeRail·Home 상세 개선 구현 기록

[확정 설계 및 시안](../design/workrail-node-detail.md) · [사용 안내](../release/user-guide.md)

- NodeRail은 수동 환경 검사와 공식 목록 갱신의 진행선을 구분한다. 제목 옆에 선택 환경과 관리자 버전을 배치하고 패널의 N을 3px 올렸다. 검색 D의 상단 반사와 독립 스크롤 제목은 기존 테마 토큰을 사용한다.
- Home은 Node 작업 전 목록 위에 진행 상태를 겹쳐 보여 준다. 작업 중 목록은 키보드·마우스 조작을 막고 WSL 취소·로그와 종료 미확인 복구는 접근할 수 있다. 오늘의 일정은 기존 표시 순서와 필터를 따르며 공유·개인 배지 다음에 달력 일수로 마감을 표시한다.
- 폴더 및 릴리스 열기는 선택 환경 ID만 받아 Main이 결정한다. Windows nvm 1.x의 검증된 root, 2.x의 InstallRoot, 실행 중인 WSL 기본 사용자의 nodenv 루트를 지원한다. 최신 릴리스 주소는 환경별로 고정되어 있다. 설치되지 않은 관리자도 환경을 선택하면 공식 페이지를 열 수 있다.
- Windows 작업 표시줄·트레이·설치 리소스는 9개 크기를 담은 레일 아이콘을 사용한다. 16px·20px에는 소형 전용 원본을 사용한다.

## 회귀 검사와 실기 범위

이전 Windows 실행에서 창 너비 500px를 참여자 한 명 표시의 전제로 사용해 '외 2명' 검사가 실패했다. 수정된 Electron 검사는 실제 참여자 영역을 측정한 뒤 전체·일부·모두 접힘, 인원 합계, 알림 비중첩과 키보드를 확인하고 측정 결과를 첨부한다. [이전 실패 기록](https://github.com/kdydesign/simple-timeline/actions/runs/44460706286)

검사에는 관리 대상 식별·폴더 경로 재검증, 공식 릴리스 열기, 날짜 경계, 진행 레이어의 위치·입력 차단, 검사 및 목록 스크롤을 포함한다. Windows 파일 탐색기 표시·기본 브라우저 선택과 외부에서 WSL을 동시에 종료하는 경우는 사용자 PC 실기 범위다. Windows 설치·업데이트와 artifact의 실행별 근거는 해당 커밋의 Application workflow에서 확인한다.

Linux x64 단위·UI·네이티브 검사를 통과한 clean `4558e55`의 Electron E2E에서 117/118개가 통과했다. 너비 660px에서 작업 중 임시 빈 인벤토리가 Home 상단 버전을 두 줄로 바꿔 아래 위젯을 43px 밀었다. 전환 중 마지막 확인 값을 ‘작업 전 확인한 Node’로 표시하도록 수정하고 같은 좁은 창·포커스·로그 스크롤 검사를 통과했다.

Linux x64의 clean `b9d2521`에서 하네스 및 전체 앱 검사 7단계를 통과했다. 각 시간대 단위 검사 489개, UI 285개, 네이티브 98개, Electron E2E 118개를 통과했다. 같은 커밋의 Windows 검사에서 임시 디렉터리의 정상 사례가 실패했다. 정상 사례의 TEMP를 실제 경로로 해석한 뒤 폴더를 생성하고, 정션 하위 및 일반 파일 거부를 함께 검사한다.
