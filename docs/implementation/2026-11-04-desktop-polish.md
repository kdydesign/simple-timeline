# 데스크톱 화면 정리

## 요청과 화면 근거

기준: `799e9340327d28fe06b8250a9c23f6230444656b`. 사용자 요청은 기존 기능·데이터·문구를 보존하면서
빈 프로젝트 안내, 오늘·hover 표시, 연월 라벨, 달력 고정 영역을 개선하는 것이다.
Linux Electron의 격리된 hotfix 테스트 프로필에서 1440×900, 1280×600 화면을 확인했다.

- 빈 프로젝트의 `일정 없음`이 날짜 격자 상단에 붙어 날짜 관련 정보처럼 보인다.
- 간트에는 오늘 열 배경이 없고 달력은 오늘 숫자만 강조한다.
- 달력 스크롤 시 요일만 남고 제목·이전/다음 달 버튼은 사라진다.
- 간트 보조 정보가 10px로 작고 프로젝트 제목과 일정 제목의 굵기가 같다.
- 헤더의 `선택 연월` 글자는 제거하되 입력의 접근성 이름과 월 선택 기능은 보존한다.

## 적용 전 디자인 계획

색상: 본문 Ink `#1B2840`, 작업면 Surface `#FFFFFF`, 바탕 Canvas `#F4F6FA`,
강조 Blue `#2563EB`, 오늘 Today `#E8F0FF`, hover Hover `#EEF2F7`.
다크 테마에서는 기존 바탕·본문 색을 유지하고 오늘/hover 배경만 각각 `#243B60`/`#2B3545`로 대응한다.
프로젝트별 막대 색상은 사용자 데이터이므로 바꾸지 않는다.

글꼴은 오프라인 Windows 환경의 맑은 고딕과 기존 시스템 폴백을 유지한다.
제목 18px, 본문 14px, 보조 정보 12px, 간격은 4px 단위로 정리한다.
날짜 숫자는 일정 폭을 유지하고 제목·메타데이터는 왼쪽 정렬한다.

```text
[앱 이름] [간트/달력] [‹ YYYY-MM › 오늘]     [테마 / 목록 / 추가]
[전체 일정과 범위]                또는 [월간 달력 / 이전·다음 달] ← 고정
[프로젝트 / 일정 | 월·일 눈금]          [월 화 수 목 금 토 일]    ← 고정
[프로젝트·참여자·일정 없음 | 날짜별 격자] [날짜별 격자·일정 막대]
```

검토: 새 카드·장식·문구·모션을 추가하지 않는다. 시간축과 프로젝트 막대가 주 정보이며,
배경 강조는 위치 파악만 돕는다. 빈 상태는 프로젝트 메타데이터에 넣어 날짜 영역과 분리한다.
달력 제목과 요일은 한 sticky 영역으로 묶어 줄바꿈에도 고정 위치가 어긋나지 않게 한다.
가상화와 1일 28px 좌표, 일정 편집·드래그 계약은 유지한다.

## 구현과 보정

- `GanttView.tsx`: 빈 안내를 참여자와 같은 프로젝트 메타데이터 줄로 옮기고, 프로젝트 제목을 굵게 구분한다.
  오늘/hover 열은 현재 가상 행 위에만 표시한다. 전체 날짜 범위만큼 DOM을 만들지 않는다.
- `CalendarView.tsx`: 제목·월 이동·요일을 한 sticky 영역으로 묶는다. 막대 위의 포인터도
  실제 날짜 칸으로 계산해 빈 칸과 같은 강조를 적용한다.
- `Toolbar.tsx`: 보이는 연월 라벨만 제거하고 `aria-label`과 입력 핸들러는 유지한다.
- `styles.css`: 보조 정보·날짜 눈금 크기, 여백, 라이트/다크 배경을 정리한다.
  기존 중복 header/workspace 규칙을 합치고 고정 위치를 main padding 변수에 맞춘다.
- 스크롤·월·모드 전환 뒤 hover를 해제한다. 공통 button hover와 날짜 강조가 겹쳐 농도가 달라지던 부분을 보정했다.
- 새 회귀 검사에서 날짜 헤더가 1px 독립 스크롤되어 hover가 해제되는 현상을 확인했다.
  날짜 헤더의 overflow를 clip으로 바꾸고 hover 해제 listener를 실제 main/간트 본문 스크롤에 한정했다.
  관련 7개 E2E(날짜 강조·sticky·Tab·드래그 포함)를 재실행해 통과했다.
- 독립 코드 리뷰에서 발견된 hover 상태·검사 누락을 보정했다. 최종 읽기 전용 리뷰에서 Critical/Important 지적은 없다.
