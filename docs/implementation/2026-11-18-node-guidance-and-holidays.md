# Node 경고·휴일 설정 및 MSI 판독 수정

기준 `465a356`, 사용자 Q1/Q2 선택은 [설계](../design/node-guidance-and-holiday-layout.md)를 따른다. 제품 변경 전에 설계와 [계획](../superpowers/plans/2026-11-18-node-guidance-and-holidays.md)을 작성했다.

## 변경

- Windows MSI 조회의 COM Execute/Close 출력을 억제해 단일 문자열만 반환한다. 공식 MSI 확인 불가를 비공식 설치로 단정하던 문구를 정정한다.
- Node 충돌 안내는 기존 PlanRail 노란색 계열에 요약·두 버튼을 놓고 경로와 상세 안내를 접는다. 실제 제거 확인과 설치 차단·개발 복구 창 동작은 유지한다.
- 공통/개인 휴일을 반복 위·날짜별 아래로 배치한다. 요일 저장 버튼을 요일 목록과 분리하고, 날짜 세 입력과 다음 행 우측 작업 버튼으로 정리한다. 작은 창은 입력을 줄바꿈한다.
- 초기 검사에서 기존 Home UI 검사가 항상 존재하는 패널을 기다린 뒤 비동기 공유 배지를 즉시 조회하는 문제도 관찰했다. 실제 배지가 도착하는 것을 기다리도록 assertion을 정정했으며 제품 동작·시간 제한을 바꾸지 않았다.
- 아이콘 리소스와 메뉴 버튼 스타일은 변경하지 않았다.

## 검증 기록

- 변경 전 관련 UI 검사: 새 동작 미구현 4건과 기존 Home 비동기 assertion 1건 실패. 변경 후 28개 통과.
- 새 휴일 레이아웃 E2E는 기존 좌우 배치에서 실패했고 수정 후 통과했다. 1440/980px에서 입력 세 개 동일 행·요일 일곱 개 동일 행·영역 내부 배치, 640px에서 잘림 없는 배치를 검증했다. 기존 호스트 휴일 편집·달력·간트 반영 검사도 통과했다(총 2개).
- Windows 전용 회귀는 일회성 MSI 데이터베이스를 생성해 실제 COM으로 값/없는 필드/재조회를 확인한다. Linux에서는 Windows Installer COM이 없으므로 해당 검사는 실행되지 않는다. 사용자가 제공한 PowerShell 수정 전/후 결과와 Windows 자동 검증은 별개다.
- 읽기 전용 독립 코드 검토: 추가 수정 사항 없음.
- 실패 로그와 화면은 `artifacts/node-guidance-review/`에 보존한다. Node 화면 캡처는 Linux Electron에 읽기 전용 Windows 상태를 주입한 UI 확인이며 실제 Windows 환경 검사·제거 성공 증거가 아니다.
- 전체 앱 검사·하네스 결과는 실행 완료 후 기록한다. 사용자 PC의 환경 재검사와 제거/UAC는 미검증이다.
