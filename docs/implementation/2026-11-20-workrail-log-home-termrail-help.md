# NodeRail 로그, Home 목록, TermRail 입력과 도움말

[승인된 설계](../design/workrail-log-home-termrail-help.md) · [구현 계획](../superpowers/plans/2026-11-20-workrail-log-home-termrail-help.md) · [사용자 안내](../release/user-guide.md)

## 변경 내용

- NodeRail은 작업 결과에 붙인 식별자로 새 실패를 구분한다. 현재 환경의 작업 로그를 닫으면 다시 조회하거나 메뉴를 왕복해도 접힌 상태를 유지한다. 새 실패는 노란 패널로 열린다. 진단 복사는 중립색 아이콘 버튼, 닫기는 ×이며 키보드로도 조작할 수 있다.
- 공식 목록·설치된 버전·Home은 같은 버전 표시를 사용한다. 녹색 체크는 현재 사용 중인 버전, 양방향 화살표는 설치된 버전으로 전환, 다운로드 아이콘은 설치다. Home의 참여자·버전은 각각 5개까지 표시한다. ‘외 N명’은 전체 참여자 팝업을 열고 ‘외 N개’는 같은 환경의 설치 목록 제목으로 이동한다.
- TermRail은 서버 이름이나 주소를 입력하기 전에도 시작 파일을 고를 수 있다. 메인은 편집 중인 선택을 보호하고, 저장 시 검증한 호스트·포트에 결합한다. 입력 오류와 취소를 구분하며 기저장 파일은 기존 대상에 계속 귀속된다. 서버 추가·레이아웃 저장 창에는 표준 크기의 입력과 액션을 적용했다. 사이드바 버튼은 좁은 창에서 아이콘과 접근 가능한 이름을 유지한다.
- 도움말의 공통 섹션 다음에 Home, PlanRail, NodeRail, TermRail을 배치했다. 설정 도움말의 기존 저장 키를 유지하고 전체 사용법 및 메뉴별 글을 보강했다. [촬영 파일과 환경](../../src/renderer/help/images/capture.json)

프로필 저장이 실패하면 이번 저장에서 만든 보호 파일을 정리하고 다시 저장할 수 있다. 렌더러가 중단되면 살아 있는 메인 프로세스가 미확정 파일 ID를 보관하고, 다음 정상 라이브러리를 읽을 때 참조 여부를 대조한다. 파일 결합과 프로필 기록 사이에 앱 프로세스 전체가 강제 종료되면 참조되지 않는 암호화 사본이 남을 수 있다.

## 검증 범위

일회성 Electron 프로필에서 정상 크기와 좁은 창의 TermRail 팝업·키보드 포커스 복귀, Node 상태의 두 테마 대비, Home의 참여자·설치 버전 표시와 Windows 예시 진단 복사를 확인했다. 기존 안내 그림 2장과 추가한 Home·작업 로그·서버 추가 그림 3장은 같은 방식으로 촬영했다. Windows·WSL 작업 결과의 경계와 시작 파일의 저장·취소·대상 결합은 별도 단위·UI 검사에서 확인한다.

전체 로컬 검사의 커밋·작업 트리 상태·플랫폼·단계별 결과는 `artifacts/app/latest.json`에 기록된다. 실제 Windows 설치·업데이트 검사는 해당 커밋 GitHub Actions의 Application Windows 작업과 설치본 artifact에서 확인한다. 사내 PC의 폴더 최종 이동 EPERM은 이 화면 작업과 별도인 실기 진단 항목이다.
