# 0.8.6 멤버 버전·공통 휴일·승인 요청 알림

승인: [설계](../design/member-versions-holidays-and-pairing-notices.md)의 Q1~Q11, 화면 시안 검토와 사용자의 ‘좋아 진행해’. 기존 MVP 지도는 완료 상태를 유지한다.

## 구현

- 인증된 정상 동기화 완료에 포함된 선택적 버전 헤더를 호스트에 기록한다. UI는 연결 중 실행 버전/오프라인 마지막 확인 버전/미보고 확인 불가를 구분한다. 동일 보고는 60초 이내 DB 쓰기를 합친다. 설치본 교체 시 이전 자격의 보고를 새 설치본에 귀속시키지 않는다.
- migration7은 호스트 공통 휴일표, 멤버 캐시, 버전 기록, 승인 요청 알림 이력을 추가한다. 기존 credential에 설치본 binding을 보존하여 보고 대상을 확인한다. 날짜별 휴일은 이름 필수·날짜당 하나·최대1,000개이며 기본 반복 요일은 토·일이다.
- `/v1/holidays`는 기존 인증·TLS를 사용하며 ETag와 별도 revision을 갖는다. 기존 snapshot/change 본문은 그대로다. 정상 프로젝트 동기화 뒤 순차 확인하고, 휴일 실패는 프로젝트 수신을 되돌리지 않는다. 자동 재접속·수동 동기화 때 구버전 미지원 상태도 다시 검사한다.
- 캐시 저장에 성공한 뒤에만 ETag를 승인한다. 세션이 바뀐 늦은 응답은 폐기한다. 일시 단절은 마지막 표, 직접 해제·확인된 승인 취소는 기본 토·일로 복귀한다. 프로젝트가 없어도 승인된 멤버는 수신한다.
- 간트는 날짜 눈금과 실제 트랙만, 달력은 날짜 칸과 작은 이름으로 표시한다. 오늘·선택·일정 색상과 기간·알림 계산은 유지한다. 멤버 공유 설정에는 편집 컨트롤 대신 조회용 요일 배지를 제공한다.
- 멤버 코드 확인 후 아직 호스트 승인이 필요할 때만 Windows 알림을 시도한다. 요청별 중복 억제·등록 PC별 60초 제한·전체 무음·재시작 시 결과 불명 처리 이력을 먼저 저장한다. 클릭은 현재 승인 목록을 열며 자동 승인하지 않는다. 기존 확인창이 있으면 닫힌 뒤 공유 설정을 표시한다.

## 검증과 범위

기준 HEAD `f53b165beacd576ebd3e27c83c3e1f5aff780435`의 작업 트리에서 검증한다. 최종 SHA·원격 CI는 완료 보고의 커밋과 Actions를 기준으로 한다.

- 독립 검토: 재접속 시 휴일 capability 재확인, 설치본 교체 중 버전 귀속, 알림 클릭과 기존 모달 충돌을 발견하여 보정·회귀 검사 추가. SemVer prerelease/build와 멤버 조회 전용 외형도 보정했다.
- 단위/UI: 날짜 범위·중복·주간 규칙, 구버전 본문 호환, 승인 전후·중복 알림, 초안 보존, 공유 설정 보류, 날짜 강조를 검사한다.
- 네이티브: 실제 SQLite/TLS의 프로젝트 없는 멤버 수신·실패 보존·재접속·권한 회수, v6→v7 자료 보존을 검사한다. 휴일 변경은 공유 변경 journal과 알림 발송 수를 늘리지 않는다.
- Electron: 가상 데이터·격리 프로필의 휴일 편집 및 간트/달력 화면과 기존 기능 전체 회귀를 실행한다. 도움말 이미지는 실제 테스트 renderer에서 다시 촬영한다.
- 로컬 전체 검사는 아래 최종 결과와 같이 통과했다. 실제 Windows 알림 배너, 회사망 6PC 지연·보안 정책과 사용자 인수는 별도 미검증이다.

환경: Linux x64, Node24.22.1, Electron45.2.1. 기본 DISPLAY가 작동하지 않아 작업 폴더 밖 `/workspace/output/xvfb-tools`에 받은 Xvfb로 격리 검사를 실행한다. 시스템 패키지·운영 DB·sandbox 정책은 바꾸지 않는다. 버전별 도움말 이미지 검증을 유지하기 위해 기존 0.8.5 매니페스트로 촬영 fixture를 부트스트랩한 뒤 0.8.6에서 실제 재촬영했으며, 최종 빌드는 0.8.6과 같은 버전의 실제 capture 근거를 사용한다.

초기 전체 검사는 기존 출시 버전 기대값(0.8.5)과 새 버전(0.8.6)의 불일치를 발견해 갱신했다. 다음 UI 검사 197/200 통과에서 빈 휴일 `status`가 기존 성공 안내 질의와 충돌하고 달력 native title이 기존 툴팁 정책을 위반하는 것을 확인했다. 빈 live-status와 native title을 제거하고 휴일 전체 이름은 화면 내 hover/focus 확장 및 접근성 설명으로 제공한다. 관련 UI31개 별도 검사를 통과했으며 전체를 다시 실행한다.

보정 후 UI200개·제품 빌드는 통과했다. native 보안 검사의 공유 bridge 고정 목록에 새 명명 명령 `saveHolidays`가 누락되어 실패한 한 건은 목록을 갱신했다. Node 미노출·sandbox·contextIsolation 및 전체 정확한 키 비교 단언은 그대로 유지한다.

격리 Electron 첫 전체 실행은101/103 통과였다. 보안 목록 수정 전 Playwright가 이미 읽은 기대값 한 건과, 새 승인 요청 알림이 생긴 호스트에서도 알림0건을 기대하던 기존 공유 시나리오 한 건을 확인했다. 보안 목록은 최신 테스트로 다시 실행하고, 공유 시나리오는 코드 확인 전0건→후1건 및 클릭 시 승인 목록 이동을 명시적으로 검사하도록 바꿨다. 멤버의 기존 공유 변경 알림 건수·내용 단언은 유지한다. 새 휴일 시나리오와 실제 관리/간트/달력 화면은 통과·시각 확인했다. 최종 전체 실행에서 결과를 다시 확인한다.
