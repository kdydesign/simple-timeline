# WorkRail 1.1.0 · PostRail 편집기와 Home 즐겨찾기

## 사용 흐름

- 왼쪽에서 요청 이름을 검색한다. 그룹으로 드래그하면 이름, 즐겨찾기, 다음 인덱스를 유지해 이동한다. 요청 이름 옆의 인증 배지에서 현재 설정을 확인한다. 새 요청은 인증 없이 시작한다.
- 요청에서 쿼리·경로와 헤더를 편집한다. 헤더는 키·값 표가 기본이며 raw로 전환할 수 있다. POST는 본문 없음, JSON, raw, URL 인코딩 폼, multipart, binary를 지원한다. 파일은 로컬 파일 선택기로 등록한다. 다음 실행 때 파일이 없어지면 다시 선택한다.
- 환경 관리에서 환경을 선택해 변수, 로그인 요청, 응답의 토큰 경로와 수신 API 주소를 설정한다. 유효한 토큰이 있을 때 해당 환경의 저장된 토큰을 비울 수 있다. 전송 오류는 메서드와 URL 사이에 표시한다. 느낌표를 누르면 console이 열리며, 최근 1,000줄을 앱 실행 중에만 보관한다.
- 요청과 응답의 초기 높이 비율은 3 대 7이다. 구분선을 끌거나 키보드로 조절한다. JSON은 자동으로 정렬하며, 응답의 편집본·원문을 전환하거나 편집본을 다시 정렬할 수 있다. 검색은 현재 보기에 적용하고 복사는 현재 본문 전체에 적용한다.
- Home은 즐겨찾기를 최대 다섯 개 표시한다. 실행하면 해당 행에 진행 표시가 나타난다. 반복으로 저장한 POST에는 실행 버튼 바로 아래에 ‘반복 보내기’와 저장한 횟수가 표시된다. 체크를 켜야 지정한 횟수만큼 전송한다. 완료 후 ‘결과 보기’는 해당 실행의 마지막 처리 회차를 PostRail에서 연다.

## 확인한 시나리오

Linux x64, Node 24.22.1, 기준 커밋 `cd1b7a0`에 1.1.0 변경을 반영한 작업 트리에서 일회성 Electron 프로필과 로컬 HTTP 서버로 확인했다.

- Home에서 기본 단건과 명시적 2회 전송이 각각 한 건과 두 건으로 도착했다. 결과 보기에서 마지막 회차를 열고 JSON 편집·포맷·복사, 응답 원문 보기를 확인했다.
- 창을 숨긴 상태의 전송, 재시작 뒤 인덱스 유지, 환경 인증과 console 동작을 확인했다.
- 실제 파일 선택기로 고른 테스트 파일의 binary·multipart 본문을 로컬 서버에서 수신해 바이트를 대조했다. Home 도움말의 반복 실행 이미지는 같은 Electron 실행에서 캡처했다.

## 전체 검증

저장소 하네스 7개와 Linux 앱 검사 7단계가 모두 통과했다. UTC·뉴욕·서울에서 각각 단위 검사 721개 통과·8개 건너뜀, UI 검사 373개, Electron E2E 129개 통과를 확인했다. 타입 검사, 배포 검사, 제품 빌드와 네이티브 검사도 통과했다. 결과 파일은 `artifacts/app/latest.json`이며 검사 시점은 위 기준 커밋의 수정된 작업 트리다. Windows 설치·업데이트와 실제 사내 API 인증은 이 로컬 검증의 범위 밖이다.

## 1.1.0 현장 피드백 반영

- 쿼리·헤더 표의 마지막 빈 행에 바로 입력할 수 있다. 전송 전까지 비워 둔 행은 실제 파라미터나 헤더에 포함되지 않는다. 경로 파라미터는 URL의 경로 자리표시자를 따른다.
- 응답 툴바의 ‘편집본’과 ‘원문’이 선택 상태를 표시한다. 편집본에서 수정·복사하고, 원문에서 수신 당시 내용을 읽을 수 있다. 클릭 포커스의 테두리를 제거하고 키보드 포커스는 유지했다.
- console은 HTTP 오류 상태 다음에 마스킹된 서버 오류 본문을 텍스트로 표시한다. 연결 실패는 실제 통신 오류 코드·메시지를 기록한다. console에는 오류 1건당 최대 16KiB와 세션 최근 1,000줄이 표시된다. 원문이 128Ki UTF-16 단위를 초과하면 생략 표시를 남긴다. 오류 툴팁은 패널의 스크롤·잘림 영역 밖에 표시한다.
- PostRail의 메서드·환경 컨트롤과 열린 선택지를 작게 맞추고 왼쪽 요청 행 높이를 줄였다. Home 최근 결과에서 요청명, 실행 환경, 처리 건수를 분리하고 결과 보기를 오른쪽에 배치했다. [실제 위젯 화면](../../src/renderer/help/images/postrail-repeat.png)
- TermRail의 가로·세로 분할선과 분리 창에 PostRail과 같은 그립을 사용한다. 기존 드래그 영역과 저장된 레이아웃의 분할 비율을 유지한다.

제품 버전은 요청에 따라 1.1.0으로 유지했다. 같은 버전의 설치본은 새 LAN 업데이트로 표시되지 않으므로, 설치 파일 비교 시 빌드의 소스 커밋을 확인한다.

**검증**. 기준 `1510a02`에 수정한 작업 트리, Linux x64·Node 24.22.1에서 하네스 7개와 앱 검사 7단계가 통과했다. 단위 검사는 UTC·뉴욕·서울 각각 726개 통과 및 8개 건너뜀, UI 378개, Electron E2E 131개 통과다. 실제 HTTP 404의 여러 줄 본문, 편집본 복귀, 드롭다운 항목 높이와 툴팁, 양쪽 방향 및 분리 창의 그립을 확인했다. 설치 및 업데이트 검증은 별도 Windows Actions에서 수행한다.
