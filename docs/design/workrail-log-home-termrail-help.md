# WorkRail 작업 로그, Home 목록과 TermRail 입력 개선

2026-11-20 설계 검토본. Q1~Q3의 동작을 반영했다. 대상은 NodeRail·Home·TermRail·도움말이다. [이전 설치본 피드백 설계](noderail-termrail-installed-feedback.md)

## NodeRail 작업 로그와 버전 표시

- 실패 시 PlanRail 경고와 같은 노란 표면·테두리·아이콘을 사용한다. 제목, 짧은 실패 요약, 원래의 진단 이력과 닫기를 제공한다. Windows의 진단 복사와 WSL의 기존 로그 경로·내용을 유지한다.
- **Q1 결정.** 닫기는 현재 환경의 로그 표시만 접는다. 사용자는 ‘작업 로그 보기’로 다시 연다. 새 작업이 실패하면 같은 오류 코드라도 다시 연다. 실패는 작업 한 건의 종료 결과로 식별한다. 상태 조회 때마다 바뀌는 revision이나 오류 문구 자체를 새 실패의 기준으로 쓰지 않는다. 같은 작업의 상태 갱신·메뉴 왕복·재검사만으로는 다시 열지 않는다. 성공 이력은 조회할 수 있으며 성공 자체에 경고 아이콘을 붙이지 않는다. 진행 중 작업의 취소·진행 표시와 로그 닫기를 독립시킨다.
- 공식 목록·설치된 버전·Home Node 작업에서 같은 시각 규칙을 사용한다. 가장 강조하는 ‘✓ 사용 중’은 밝은 녹색 채움의 읽기 전용 상태다. ‘사용’은 파란 글래스 버튼, ‘설치’는 다운로드 아이콘과 중립색 윤곽 버튼이다. 실제 작업 불가와 상태 확인 불가는 각각 기존 사유를 제공한다. 밝은·어두운 테마에서 글자·아이콘만으로도 구분해야 한다.

## TermRail 서버와 레이아웃

- **Q2 결정.** 새 서버에서 이름·호스트가 비어 있어도 ‘가져오기’로 파일 선택 창을 연다. 이때 빈 필수 입력 안내를 먼저 띄우지 않는다. 파일 자체의 형식·보안 저장 오류는 즉시 표시한다. 파일 선택만으로 접속하거나 실행하지 않는다.
- 파일을 고른 뒤 새 서버의 호스트·포트를 작성할 수 있다. 저장 시 기존 이름·중복·주소·포트 검사를 수행하고 첫 오류 필드로 이동한다. 검증이 실패하면 대기 중인 선택을 유지한다. 저장 성공 시 최종 호스트·포트에 결합한다. 기존 서버의 주소 또는 포트가 바뀌면 이전에 결합한 파일을 새 대상에 쓰려면 재선택해야 한다.
- 원문·인증 정보는 메인 프로세스의 기존 보호 저장 경계를 따른다. 임시 선택은 해당 편집 창에 귀속시키고, 취소·창 닫기·파일 교체 시 정리한다. 실패한 저장은 부분 적용하지 않는다.
- 서버 추가와 레이아웃 저장 팝업은 공통 대화상자의 제목, 입력 높이, 여백, 우측 취소·저장 버튼을 따른다. 터미널 본문·사이드바 행·탭은 기존 밀도를 유지한다. 사이드바의 ‘＋ 추가’와 ‘저장’에는 작은 글래스 윤곽과 구별되는 아이콘·키보드 포커스를 적용한다.

## Home 위젯의 표시 한도

- 연결된 참여자와 선택 환경의 설치 버전을 각각 최대 5개까지 바로 표시한다. 0개는 기존 빈 상태, 1~5개는 목록만, 6개 이상은 전체 수에서 5를 뺀 수를 ‘외 N명’ 또는 ‘외 N개’로 표시한다. PlanRail 하단 상태 바는 기존 너비 기준을 따른다.
- **Q3 결정.** ‘외 N명’은 현재 연결된 전체 참여자의 이름·버전·연결 상태를 팝업으로 보여준다. 닫기 또는 Esc 후 원래 버튼으로 포커스가 돌아온다. ‘외 N개’는 동일 환경의 NodeRail 설치된 버전 목록으로 이동한다. 목록을 화면에 보이고 키보드 포커스를 옮긴다. 이 이동은 버전을 전환하지 않는다.
- 권장 표시 순서는 현재 사용 버전 우선, 나머지는 기존 버전 순서다. 실제 작업 중·오류 시 기존 Home 진행·복구 표시를 유지한다.

## 도움말

목차 순서는 **공통 → Home → PlanRail → NodeRail → TermRail**이다. 공통에는 WorkRail 시작·메뉴 이동·설정·트레이·도움말 사용법을 두고, Home에는 위젯과 전체 목록 이동, PlanRail에는 일정·공유, NodeRail에는 환경·설치·전환·작업 로그, TermRail에는 서버·시작 파일·분할·레이아웃을 둔다. 기존 메뉴별 도움말 열기와 읽기 위치·검색 결과의 소속 표시를 유지한다. 기존 ‘공통 설정’의 읽기 위치는 공통 섹션에서 이어간다. 화면 위치가 문장만으로 불명확한 항목은 구현 후 예시 데이터로 촬영하며 변경 전 이미지는 갱신한다.

## 인수 예시

1. 같은 설치 오류가 다시 발생한 경우와 단순 재검사를 구분한다. 로그를 닫은 뒤 새 실패에서만 자동으로 열린다.
2. 빈 서버 이름에서 클릭 또는 Tab으로 ‘가져오기’로 이동해도 이름 오류가 먼저 뜨지 않아야 한다. 파일을 고른 뒤 저장 오류를 확인하고, 이름·호스트를 입력해 다시 저장한다. 취소·저장 실패·기존 서버 주소 변경 시 파일의 귀속도 확인한다.
3. 참여자·설치 버전을 각각 0·5·6개로 확인한다. 6개에서 팝업은 전체 6명, NodeRail은 전체 6개를 표시한다.
4. 두 테마에서 버전 상태의 강조 순서, 팝업 키보드 조작, 다섯 도움말 섹션의 순서와 메뉴별 진입을 확인한다.
