# Node 충돌 안내와 휴일 설정 후속 개선

2026-11-18. 사용자가 MSI 판독 결함 수정과 화면 개선을 요청했다. grill-with-docs Q1에서 요약·버튼과 접힌 상세 정보, Q2에서 반복/날짜별 휴일의 위아래 배치를 선택했다. 이 문서는 해당 후속 변경의 기준이며 이전 아이콘 교체·크기 개선은 적용 보류를 유지한다.

## 확인한 문제

- 사용자 Windows 개발 환경의 Node 24.22.3 실행 파일은 공식 SHA256과 일치하고 서명이 유효하다. Node MSI 등록은 하나이고 캐시 MSI 서명도 유효하다.
- `Read-MsiValue`의 COM `Execute()`·`Close()` 반환값이 PowerShell 출력에 섞여 문자열 대신 배열을 만든다. 사용자는 두 반환값을 `[void]`로 버린 진단에서 정상 Component GUID와 Node 경로를 확인했다. 이 증거는 실제 제거/UAC 또는 모든 검증 조건의 통과를 의미하지 않는다.
- NodeScreen과 NodeRecovery가 충돌·제거·수동 설치 설명을 중복해서 펼친다.
- 휴일 설정의 좁은 좌측 열에서 반복 요일과 저장 버튼이 함께 줄바꿈된다. 날짜 폼은 CSS가 명시적으로 두 열로 덮어써 이름을 다음 줄에 놓는다. 스크린샷 왼쪽 잘림 전체의 원인을 캡처만으로 단정하지 않는다.

## 선택한 접근

| 결정 | 사용자 선택 | 대안과 이유 |
| --- | --- | --- |
| Node 안내 | 짧은 요약·두 버튼, 접힌 자세히 | 상세 전체 노출보다 목록을 위한 높이를 확보하면서 진단 정보는 보존 |
| 휴일 배치 | 반복 위 / 날짜별 아래 전체 너비 | 좌우 너비 조정보다 요일과 날짜 세 입력의 공간을 안정적으로 확보 |

### NodeRail

현재 사용 버전 영역 아래, 공식 배포 목록 위에 하나의 얇은 노란 경고 패널을 둔다. PlanRail 툴바 아래 `.reminder-notice`의 반투명 노랑 `#effb3a1c`, 기존 본문 색·13px 글꼴·글래스 버튼을 재사용한다. 경고 아이콘과 문구도 함께 제공해 색만으로 상태를 알리지 않는다.

```text
⚠ Node 환경 충돌
기존 Node.js를 제거한 뒤 nvm-windows를 설치해 주세요.
[Node.js 제거] [nvm-windows 설치(비활성)]  기존 Node.js 제거 후 설치할 수 있습니다.
▸ 자세히
```

- 두 버튼은 같은 줄에 놓고, 매우 좁은 공간에서는 잘리지 않도록 줄바꿈한다.
- 기존 Node와 nvm 미설치 조합에서 제거·설치 버튼을 모두 표시한다. 검증된 MSI에만 제거를 허용하고, 충돌 해소 확인 전 설치는 비활성화한다. 자동 연속 설치는 추가하지 않는다.
- 검증 실패 시 요약에 `제거할 Node.js 설치 정보를 확인하지 못했습니다.`를 표시한다. 비공식 설치라고 단정하지 않는다. 비활성 사유는 짧게 노출하며 자세한 경로·충돌 설명·검증 안내·수동 설치 주소는 `자세히`로 접는다.
- nvm만 없는 상태에서는 `nvm-windows를 설치해 Node 버전을 관리하세요.`와 설치 버튼을 표시한다. 다른 관리자·미지원 버전·PATH 충돌은 기존 검사 의미를 유지하고 적절한 수동 안내를 제공한다.
- 진행·실패·재부팅 필요·별도 관리 창 활성 상태는 접힌 상세 속에 숨기지 않는다. 제거 영향 확인과 개발 모드의 독립 관리 창 인계는 유지한다.
- 이번 변경은 공통 실패 문구를 정확하게 고치는 범위다. 모든 검사 단계의 진단 코드 세분화는 별도 과제이며 검증을 우회하지 않는다.

### 휴일 관리

```text
반복 휴일
[월] [화] [수] [목] [금] [토] [일]        [반복 요일 저장]

날짜별 휴일 (공통 / 개인)
기존 휴일 목록
시작일              종료일              휴일 이름
[날짜 선택]         [날짜 선택]         [이름 입력]
                                 [취소] [휴일 추가/저장]
```

- 공통·개인 모두 세로 두 영역, 반복 요일은 일곱 개가 같은 줄이고 저장 버튼은 독립된 작업 영역이다. 너비가 부족하면 저장 버튼만 다음 줄로 이동한다.
- 일반 설정 창에서 시작일·종료일·휴일 이름을 세 열 한 줄로 표시한다. 취소·추가는 다음 줄 우측. 좁은 창에서는 가림이나 가로 넘침보다 입력 줄바꿈을 우선한다.
- 기존 타이포그래피·색·선택 상태·입력 높이를 유지한다. 날짜 선택 팝업, 긴 이름, 검증 오류가 잘리지 않도록 실제 화면에서 확인한다.
- 호스트 공통/개인 편집, 멤버 개인 편집·공통 조회 전용 권한은 변경하지 않는다.

## 구현과 검증

MSI 조회 함수에서 불필요한 COM 출력을 제거한다. Windows에서 일회성 MSI 데이터베이스를 만들어 실제 COM을 거치는 회귀 검사를 추가한다. 운영 Node 설치를 변경하지 않는다. Linux 검증은 Windows COM 검증을 대신하지 않는다.

UI 검사는 접힌 상세 정보와 제거/설치 순서·비활성 상태를 확인한다. 실제 브라우저 레이아웃 검사는 일반/좁은 설정 너비에서 요일·입력·버튼 경계를 확인한다. 기존 전체 앱 검사와 하네스 검사를 순차 실행하고, 실행 환경·미검증 범위를 결과에 기록한다.
