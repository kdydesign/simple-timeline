# Flat·반투명 데스크톱 재설계 — C안

상태: **사용자가 시안 C를 선택하고 고정 크기·내부 스크롤을 지시한 설계**.
기준 제품 소스: `da33c7794ecf90944e74db48aee33193a2aee064`. 결정일: 2026-11-04.
이번 변경은 설계 문서와 독립 HTML 미리보기다. 제품 구현 완료를 뜻하지 않는다.

## 선택과 근거

사용자가 frontend-design과 grilling을 통한 협의, 4개 시안 비교, 검토 후 커밋·push를 요청했다.
A 사이드바, B 아이콘 레일+패널, C 상단 팝오버, D 통합 프로젝트 열을 비교한 뒤
**“C로 진행하되 크기는 시안대로의 크기에서 프로젝트 목록이 늘어나면 스크롤이 생기도록”** 지시했다.
따라서 프로젝트 관리 목록을 상단 아이콘의 팝오버에 배치한다.

- Q1: 앱 내부 반투명 표현. OS 바탕화면이 비치는 효과를 요구하지 않는다.
- Q2: 도구 모음은 아이콘, 저장·취소·삭제 확인은 텍스트. 모든 버튼에 툴팁을 제공한다.
- Q3: 탐색 구조가 다른 4안 비교.
- Q4: 창 버튼까지 앱에 맞춘 커스텀 아이콘.
- Q5: 드롭다운·날짜 선택기를 입력 옆 팝오버로 통일.
- Q6: C 선택, 팝오버 크기 유지, 항목 증가 시 내부 스크롤.

## 프로젝트 목록

- 기존 본문 위의 목록을 제거하고 상단 폴더 아이콘으로 연다. 간트·달력에서 같은 관리 목록을 사용한다.
- 기본 크기는 원본 C 미리보기에서 측정한 **너비 290px, 높이 442px**다.
  프로젝트가 늘어도 팝오버를 키우지 않고 가운데 목록만 세로 스크롤한다.
- 상단 제목·닫기 버튼과 하단 프로젝트 추가 버튼은 스크롤 영역 밖에 고정한다.
- 창 높이가 작으면 화면 안에 들어오도록 최대 높이를 줄인다. 미리보기 기준 `100vh - 124px`이며,
  실제 구현은 트리거 위치·창 배율·하단 여백을 기준으로 잘림을 방지한다.
- 목록은 기존 생성 순서를 유지한다. 이름·색상·참여자·일정 수를 표시하고 긴 이름은 생략 표시와 전체 이름 툴팁을 병행한다.
- 프로젝트 이름 클릭은 편집, 행의 +는 해당 프로젝트 일정 추가다. 빈 프로젝트도 목록에서 접근할 수 있다.
  프로젝트 선택에 따른 일정 필터링·검색 기능은 이번 설계에 포함하지 않는다.
- 팝오버의 Escape·외부 클릭은 목록을 닫고, 키보드로 닫을 때는 트리거에 포커스를 돌린다.
  긴 목록 안에서도 키보드로 각 편집·추가 버튼과 스크롤 영역에 접근할 수 있어야 한다.

## 창과 도구 모음

- OS 기본 제목 표시줄을 앱 헤더와 통합한다. 오른쪽 위에 최소화·최대화/복원·닫기를 커스텀 아이콘으로 제공한다.
- 버튼을 제외한 제목 영역은 창 드래그 영역이다. 가장자리 크기 조절과 제목 영역 더블 클릭 최대화/복원을 유지한다.
- 닫기는 기존 main의 close 경로를 거쳐 저장 중 대기·미저장 변경 확인을 보존한다.
  renderer에 Node·파일·DB 권한을 열지 않는다. 필요한 창 조작 API는 구현 단계에서 제한된 명령으로 설계한다.
- 간트/달력, 연월 이동, 오늘, 테마, 프로젝트 추가, 일정 추가를 일관된 선형 아이콘으로 표현한다.
  각 버튼은 접근성 이름을 가지며 hover와 키보드 포커스에서 설명을 보여준다.
- 저장·취소·삭제 확인은 텍스트로 결과를 명확히 한다. 비활성·선택·hover·키보드 포커스를 구분한다.
- Windows Snap 및 실제 창 동작은 시안으로 검증되지 않았다. 구현 단계에서 대상 Windows 환경에서 확인한다.

다크 작업면은 `#17222E`, 본문은 `#E4ECF5`를 기준으로 한다.
반투명과 제한된 blur는 상단·프로젝트 팝오버에 집중하고 날짜 격자·입력 영역의 대비를 확보한다.
평면적인 구획과 얇은 구분선을 사용하고 그림자는 팝오버에 한정한다. 장식용 카드·애니메이션을 추가하지 않는다.

기존 오프라인 맑은 고딕·시스템 폴백을 사용한다. 제목 18px, 본문 14px, 보조 12px,
간격 4/8/12/16/24px를 기준으로 한다. 프로젝트 색상 데이터는 유지하고 막대 선과 옅은 채움에 적용한다.
사용자 지정 색상에 대한 대비는 실제 구현 시 검사한다. 시안의 예시 색상만으로 모든 색상의 가독성을 보증하지 않는다.

## 드롭다운·날짜 선택기

- 입력 바로 아래에 겹쳐 열리며 폼을 밀지 않는다. 화면 아래 공간이 부족하면 위로 연다.
- 프로젝트 선택·월 선택·날짜 선택기의 테두리·간격·선택/hover/포커스 표현을 통일한다.
- 드롭다운은 현재 선택과 선택 가능한 항목을 구별하고, 긴 목록은 내부 스크롤한다.
  키보드 탐색·선택·Escape 닫기·입력으로 포커스 복귀를 제공한다.
- 날짜는 기존 한국어·월요일 시작, YYYY-MM-DD 직접 입력, 연도 직접 입력과 월 선택, 0001~9999년을 유지한다.
- 오늘과 선택 날짜를 구분한다. 날짜 선택은 입력에만 반영하며 실제 저장은 저장 버튼을 사용한다.
- 중첩 팝오버에서 Escape는 가장 안쪽부터 닫는다. 열고 닫는 동작이 미저장 입력을 버리지 않아야 한다.

## 유지할 제품 계약

오늘 이동·선택 테마 저장·성공 토스트·지속 오류·미저장 보호를 유지한다.
[도메인 규칙](domain-rules.md)과 [권한·저장 구조](architecture.md)를 변경하지 않는다.
기존 1일 28px·가상화·전체 일정 범위도 유지한다. 시안 날짜 축은 비교를 위한 예시 비율이다.
모바일은 범위 밖이며 기존 데스크톱 창 크기·배율·키보드 접근을 검증한다.
앱 명칭·아이콘·설치 정책의 변경은 이번 선택에 포함하지 않는다.
