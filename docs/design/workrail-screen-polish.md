# WorkRail 화면 정리 — Home · PlanRail · NodeRail

2026-11-18. 상태: **전체 설계·시안 확인 대기**. 사용자의 8개 요청과 Q1~Q4 선택을 기록하고 독립 설계 검토를 마쳤다. 제품 코드 변경은 요청받지 않았으며 구현하지 않는다.
기준: `76d9b10`의 WorkRail 1.0.0. [상단 탭 B](team-tool-expansion.md#q10-변경-반영-기준--상단-탭-b) 및 [Node 충돌 해결 확정 설계](node-conflict-removal.md)를 유지하고 이번 화면 변경을 결합한다.

## 목표와 범위

현재 딥 그레이·스틸 블루 글래스 재질을 유지하면서 Node 목록의 읽기·정렬·진행 표시를 정리하고 일정 관련 상태를 해당 화면에 배치한다. 기존 이름 Planrail과 Node 관리의 **현재 사용자 화면 표기**를 PlanRail·NodeRail로 통일한다. 과거 기록이나 설치 식별자·프로필·실행 파일·업데이트 파일명 변경은 포함하지 않는다.

## 코드·시안 대조

- [ToolDock.tsx](../../src/renderer/workrail/ToolDock.tsx)는 현재 홈 / Planrail / Node 관리와 Lucide `Hexagon`을 사용한다. N은 CSS에 가려진 것이 아니라 경로 자체가 없다. 기존 검토 시안 `/workspace/output/nw-tool-concepts/index.html`에는 육각형과 N 경로가 있다.
- [NodeScreen.tsx](../../src/renderer/workrail/NodeScreen.tsx)의 새로고침 중 문구와 최초 로딩의 빈 상태 문구는 두 곳에 있다. 둘 다 제거 대상이다. 오류·빈 결과·설치 진행 문구는 별개다.
- [workrail.css](../../src/renderer/workrail.css)는 표 기본 정렬을 start, 작업 열을 end로 두며 행 버전은 th다. 컬럼별 정렬 명령은 없다. 설치 패널은 `align-items: start`인 grid에서 내용 높이만 차지한다.
- [SavingOverlay.tsx](../../src/renderer/components/SavingOverlay.tsx)는 진행 바 외에 화면 입력 차단·포커스 이동도 한다. 목록 조회에는 이 차단 동작을 복제하지 않는다. [forest-crystal.css](../../src/renderer/forest-crystal.css)의 2px 진행 선, accent 색, 1.1초 흐름과 reduced-motion 표현만 재사용한다.
- [App.tsx](../../src/renderer/App.tsx)는 PlanRail일 때만 Titlebar에 공유 상태를 준다. 현재 Home에는 상단 역할 배지가 없다. 이번 설계는 PlanRail 상단 배지를 없애고 Home 카드와 PlanRail 하단에 상태 표현을 모으는 변경이다.
- [Home.tsx](../../src/renderer/workrail/Home.tsx)의 ‘일정 공유’에는 역할·연결 설명·마지막 정상 확인·오류가 이미 있다. ‘작업 현황’과 날짜가 같은 행에 있다.
- 현재 NodeScreen은 메뉴 선택에 따라 조건부 마운트되므로 검색·필터가 화면을 떠날 때 사라질 수 있다. 이번 설계의 검색·필터·정렬·스크롤 보존은 상태 수명을 별도로 정리해야 하며 기존 구현이 이미 충족한다고 가정하지 않는다.
- 트레이의 전체 무음은 main의 [notifications.ts](../../src/main/db/notifications.ts)에 저장된다. [reminder-api.ts](../../src/shared/reminder-api.ts)는 현재 무음 값을 제공하지 않는다. 오류 개수 0이나 공유 변경 알림 스위치로 무음을 추정해서는 안 된다.
- 기존 비교 시안의 하단 ‘일정 공유 연결됨 / 일정 알림 켜짐’은 고정 예시다. 제품에는 실제 상태에 따른 표현이 필요하다.

## NodeRail 목록

### 진행 표시

- 테이블 프레임을 최초 로딩·빈 결과·조회 실패에서도 유지한다. 첫 조회와 새로고침 모두 프레임의 상단 보더에 진행 선을 표시한다. 문구 제거로 테이블 위치나 높이가 움직이지 않게 한다.
- 진행률을 알 수 없는 조회이므로 숫자 퍼센트는 만들지 않는다. PlanRail의 색상·두께·흐름 표현을 재사용하되 NodeRail 목록 영역에만 적용한다.
- 이전 목록이 있으면 조회 중에도 유지한다. 데이터가 없을 때는 헤더 아래 빈 공간과 진행 선으로 표시하며, 아직 로딩 중인 상태를 ‘버전 없음’으로 단정하지 않는다.
- 화면의 로딩 문장은 제거하되 스크린리더에는 목록 조회 중/완료 상태를 알리고 테이블 영역의 aria-busy를 설정한다. reduced-motion에서는 움직이지 않는 선으로 표시한다.
- 중복 새로고침만 막는다. 메뉴 전환·검색·필터·정렬은 허용하되 기존 Node 설치·사용의 busy 및 신뢰 가능한 목록 조건은 그대로 따른다. 저장용 차단 overlay를 사용하지 않는다.
- 조회 실패 시 진행 선을 끝내고 실제 오류·재시도·마지막 목록 안내를 유지한다. 설치·전환 진행과 오류를 숨기는 변경이 아니다.

### 정렬 규칙

- 헤더·본문의 모든 셀과 버튼을 가로 가운데 정렬하고 행 안에서 세로 중앙을 맞춘다. 헤더의 정렬 아이콘 공간을 양쪽 대칭으로 확보해 제목 중심과 데이터 중심이 어긋나지 않게 한다.
- 기본은 Node 버전 내림차순이다. Node와 npm 버전은 각 숫자 구성요소로 비교한다. 한 번에 한 컬럼만 정렬하며 같은 헤더를 다시 누르면 방향을 반전한다.
- 새 컬럼의 첫 방향은 Node/npm 최신순, 분류는 LTS 우선, 상태는 사용 중 우선으로 제안한다. 분류는 LTS 그룹 → 일반 그룹, 같은 그룹은 코드명 순으로 비교한다. 상태 순서는 사용 중 → 설치됨 → 미설치다.
- 값이 없거나 확인되지 않은 npm·분류·상태는 두 방향 모두 맨 뒤다. 같은 정렬값의 타이는 Node 버전 내림차순으로 고정해 행 순서가 흔들리지 않게 한다.
- 현재 화면에 표시하는 상태와 같은 기준으로 정렬한다. 오래된 설치 목록·연결 오류를 최신 정상 상태로 바꾸지 않는다.
- 전체 조회 목록에 검색·필터·정렬을 적용한 뒤 표시 개수를 제한한다. 기존 ‘버전 더 보기’는 테이블 스크롤 영역 안에서 유지한다. 필터·검색·정렬 변경 시 표시 개수를 초기값으로 되돌리고 목록 스크롤을 위로 이동한다.
- 메뉴 이동·목록 새로고침에서는 선택한 검색·필터·정렬을 유지한다. 재조회 결과가 바뀌면 같은 규칙으로 재정렬한다. 앱 재시작 후 정렬 복원은 범위 밖이다.
- 헤더는 키보드로 동작하는 버튼과 aria-sort를 사용한다. 현재 방향은 색뿐 아니라 화살표로도 구분한다. 작업 열은 제목·버튼 가운데 정렬만 적용한다.

### 패널 높이

- 넓은 화면에서는 공식 목록 프레임과 설치된 버전 패널의 위·아래 경계를 같은 grid 행에 맞춘다. 목록 제목·검색 도구는 이 공통 행 위에 둔다. 출처 문구는 프레임 아래이며 하단 정렬 기준에 포함하지 않는다.
- 앱 창에서 제목 표시줄·상단 메뉴·현재 환경·충돌 안내·검색 영역을 제외한 공간을 사용한다. 목록 프레임과 설치 패널을 각각 내부 스크롤하며 헤더는 내용에 가려지지 않도록 유지한다.
- 새로고침·검색 결과 0건·설치 버전 0건에서도 두 프레임 높이는 유지한다. 설치 항목이 적다고 오른쪽 패널만 줄이지 않는다.
- 좁은 폭에서는 기존 반응형의 단일 열 전환을 유지하고, 세로로 쌓인 두 패널의 하단 일치를 강제하지 않는다. 낮은 창이나 긴 오류 안내에는 최소 읽기 공간을 보장하며 페이지 스크롤을 허용한다. UI를 잘라 고정 높이를 지키지 않는다.

## 메뉴와 아이콘

- 상단 B 메뉴의 라벨은 **Home / PlanRail / NodeRail**이다. 이동 버튼·현재 화면 접근성 이름·새 도움말 등 현재 UI에서 도구를 지칭하는 표기도 맞춘다. Node.js·npm·nvm-windows라는 기술 이름은 바꾸지 않는다.
- NodeRail은 육각형 안에 단순한 N이 포함된 SVG를 사용한다. 선택·비선택·포커스 상태와 작은 메뉴 크기에서 대비·선 두께를 검증한다. 텍스트 폰트 로딩에 의존하지 않고 N도 벡터 경로로 표현한다.
- 같은 도구를 나타내는 Home 개발 환경 카드와 NodeRail 현재 환경 아이콘도 같은 심벌을 재사용한다. 메뉴 텍스트가 있으므로 아이콘 자체는 중복 낭독하지 않는다.

## PlanRail 하단 상태 바

- PlanRail 화면에만 콘텐츠 아래의 독립된 상태 바를 둔다. 상단 B 메뉴와 함께 사용하며 하단 도크를 되살리지 않는다. 간트·달력의 가로 스크롤·편집 패널·알림을 덮지 않게 실제 레이아웃 공간을 확보한다.
- 읽기 전용 요약이다. 역할 배지 + 공유 상태, 일정 알림 정책을 표시한다. 새로운 설정 토글·재시도 버튼·승인 기능을 추가하지 않는다. 자세한 오류와 기존 조작은 원래 UI에서 유지한다.
- 공유 상태는 [sharingDescription](../../src/shared/sharing-status.ts)과 같은 실제 상태를 사용한다. 호스트는 ‘공유 제공 중’, 멤버 정상은 ‘연결 정상’, 개인은 ‘공유 미설정’으로 구분한다. 중지·연결 확인·승인 대기·단절·승인 취소·오류를 정상으로 표시하지 않는다. null/조회 실패는 확인 불가다.
- role과 연결 상태는 별개다. 연결이 끊겨도 마지막 역할은 멤버일 수 있다. 마지막 정상 확인 시간은 툴팁/접근 가능한 설명에 표시하며 현재 정상 연결의 근거로 쓰지 않는다.
- 트레이의 전체 무음=true면 ‘전체 알림 무음’, false면 ‘일정 알림 켜짐’을 표시한다. 초기 조회 중은 ‘알림 상태 확인 중’, 읽기 실패는 ‘알림 상태 확인 불가’다. 개별 일정 알림 설정·Windows 방해 금지·배너 수신 여부를 뜻하지 않는다는 설명을 제공한다.
- 무음 해제 직후의 공유 권한 재확인과 기존 실패/결과 불명/기록 오류는 원래 진단 영역에서 계속 알린다. 하단의 정책 요약을 알림 성공 판정으로 쓰지 않는다.
- 새 제한된 읽기 상태와 변경 통지를 main/preload/shared 계약에 추가해야 한다. main이 실제 저장소 조회 결과를 제공하고 트레이 변경이 성공한 뒤 통지한다. 초기/재포커스/오류 복구 시 재조회한다. renderer에 DB·파일 권한이나 무음 변경 명령을 새로 열지 않는다.

## Home

- ‘작업 현황’ 글자만 제거하고 오늘 날짜는 유지한다. 빈 제목 자리를 남기지 않고 기존 패널 간격을 유지한다. 페이지의 접근 가능한 이름은 Home으로 제공한다.
- 기존 ‘일정 공유’ 패널 제목을 **PlanRail 상태**로 바꾼다. 역할 배지(개인 전용·호스트·멤버), 공유 연결 상태 배지, 마지막 정상 확인·실제 오류를 모은다.
- 공유 상태의 의미와 데이터는 PlanRail 하단과 동일하다. 상단 제목 표시줄에서는 역할·연결 배지를 모든 메뉴에서 제거한다. UPDATE·설정·도움말·릴리즈노트·창 제어는 유지한다.
- 오늘의 일정·내 개발 환경·Node 작업 패널은 유지한다. NodeRail 화면에 일정 상태 배지를 따로 추가하지 않는다.

## 검토용 시안과 인수

[클릭형 시안](mockups/workrail-screen-polish.html)을 제품과 분리된 HTML로 작성했다. Home·PlanRail·NodeRail 탭, 목록 정렬·새로고침 진행, 두 패널 스크롤, 역할·연결·무음 상태를 예시 데이터로 확인할 수 있다. 실제 공식 목록 조회·Node 설치/삭제·DB·알림 전송은 수행하지 않는다. 설치·사용·창 제어 등 범위 밖 동작은 예시 안내만 표시한다. 레이아웃·상태 표현 검토용이며 기존 제품의 전체 기능을 재현한 것은 아니다.

작업공간의 `/workspace/output/workrail-screen-polish/`에 Home·PlanRail·NodeRail 및 로딩·실패·좁은 폭 캡처와 `checks.json`을 보관했다. Chromium sandbox를 유지한 검토에서 1440×1000의 두 패널 위·아래 차이는 각각 0px, 페이지 JavaScript 오류는 0건이었다. 숫자 정렬·검색·메뉴 전환 시 예시 상태 유지·최초/재조회/실패·640px 폭의 가로 넘침 없음·reduced-motion을 확인했다. 이 결과는 시안 검증이며 제품 앱의 테스트 결과가 아니다.

독립 설계 검토에서는 구현 계획 수립을 막는 미답 질문과 코드 사실의 모순을 발견하지 않았다. NodeScreen 상태 수명과 무음 읽기/변경 통지는 후속 구현에 필요한 실제 변경으로 확인했다. 전체 설계와 시안의 최종 사용자 확인은 아직 대기 중이다.

- NodeRail: 최초 조회/재조회/실패/0건에서 상단 선과 표 위치, 헤더/셀 가운데 정렬, 4개 정렬키·숫자 비교·빈 값·타이·필터 후 정렬, 넓은/좁은/낮은 창, 독립 스크롤.
- 메뉴: 상단 B·정확한 라벨·N 가독성, 키보드·고대비·reduced-motion, 메뉴 이동 후 입력·날짜·스크롤·정렬 유지.
- PlanRail: 개인/호스트/멤버 및 연결의 모든 상태, 무음 on/off·조회 중/실패·트레이 변경 전파, 기존 오류 안내 유지, 상태 바가 간트·달력·편집·팝업을 가리지 않음.
- Home: 제목 문구 제거·날짜 유지, 카드명·배지·오류·마지막 확인, 기존 오늘 일정·개발 환경 정보 유지.
- 전체: 설치 식별자·버전·운영 데이터·공유·알림 정책은 이번 이름/화면 정리로 변경하지 않음. 실제 구현 시 타입·단위/UI·Electron 통합·앱 전체 검사를 변경 범위에 맞춰 실행한다.

현재는 설계·시안 검토 단계다. 전체 설계 승인과 제품 구현 요청을 구분한다.
