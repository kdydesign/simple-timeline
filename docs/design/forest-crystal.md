# Forest Crystal — 승인된 유리 화면

상태: 2026-11-10 사용자가 기능별 이미지와 보정 시안을 승인하고 실제 디자인 변경을 요청했다.
2026-11-11 외곽·투명도·다크 팔레트·아이콘은 아래 **0.6.4** 승인 내용으로 대체한다. 이전 절은 당시 선택 근거다.
이 문서는 C안 배치·Planrail 기능 계약을 유지하면서 시각 표현을 대체한다.
승인 범위는 데스크톱이며 날짜·DB·공유 권한·알림·드래그 동작을 바꾸지 않는다.

## 승인한 방향

- Forest Crystal 대표색 `#075E54`. 큰 실행 창은 두꺼운 유리 테두리, 배경의 색과 형태가 흐리게 비치는 표면이다.
- 버튼은 내부가 비치는 낮은 유리 형태다. 강한 돌출·두꺼운 이중 테두리·과한 반사는 줄인다.
- 선택된 전체/간트·달력, 저장, 상단 일정 추가는 같은 연한 그린 배경·진한 그린 테두리와 글자다. 진한 단색 저장 버튼은 사용자가 제외했다.
- 툴바·간트·편집 패널의 간격을 넓히고 반투명 표면을 통일한다. 달력은 **툴바와 같은 투명도**다.
- 달력 제목과 날짜 격자는 하나의 패널이다. 날짜 격자를 감싸는 별도 둥근 패널은 만들지 않는다.
- 프로젝트 목록은 기존 290×442px 팝오버를 버튼 바로 아래에 왼쪽 정렬한다. 말풍선 꼬리·간트와의 연결 도형을 넣지 않는다.
- 목록 자체는 더 투명하게, 뒤쪽 내용은 강하게 흐리게 한다. 목록 내부만 스크롤하며 하단 프로젝트 추가는 오른쪽 정렬 아이콘 버튼이다. 접근 가능한 이름은 유지한다.
- 달력 전환 아이콘은 날짜 격자와 상단 고리가 있는 달력 모양이다.
- 다크 모드는 짙은 숲색의 반투명 유리, 밝은 글자, 같은 연한 그린 조작부를 사용한다.

## 구현 선택과 근거

이미지의 표면·배치가 승인 기준이며, 생성 이미지의 임의 문구·잘못된 날짜·생략 필드는 기능 변경 근거가 아니다.
프로젝트 색상·사용자 데이터·알림 필드·기존 한국어 문구·저장/취소/삭제 흐름을 보존한다.

기존 React/shadcn/Radix 컴포넌트와 가상화 좌표 계산을 유지하고 최종 재질 스타일을 한 파일에 둔다.
팔레트: forest `#075E54`, ink `#123B32`, jade `#B2E0CC`, pearl `#E8F3EF`, smoke `#142D27`, mist `#ECF6F1`.
Windows의 맑은 고딕과 기존 시스템 글꼴을 사용한다. 프로젝트 15px/700, 일정 13px/400, 보조 정보 12px 규칙은 유지한다.
패널 간격 기본 18px, 작은 데스크톱 12px. 창 조작부·모달·팝오버의 클릭/포커스 경로는 유지한다.

실제 바탕화면 투과는 Electron의 Windows 11 22H2+ `backgroundMaterial: acrylic`을 사용한다.
일반 창의 크기 조절·최대화를 유지하며 `transparent: true`의 투명 창 방식은 사용하지 않는다.
지원하지 않는 OS에는 같은 CSS 재질과 불투명 기본 배경을 사용한다. 운영체제의 투명 효과 설정에 따른 결과는 실기 검증 대상이다.
CSS 블러는 패널/팝오버에 한정하고 일정 막대별 블러·상시 애니메이션·원격 폰트·새 라이브러리는 추가하지 않는다.

## 검증 기준

- 목록의 위치·고정 크기·스크롤·아이콘 추가 버튼·Escape와 포커스 복귀.
- 툴바/달력 동일 재질, 단일 달력 표면, 라이트/다크의 선택 상태와 입력 가독성.
- 일정 추가/편집, 드래그·리사이즈·확대/이동, 공유 조회 전용, 미저장 보호 회귀.
- 1440×900 및 1280×820 화면 비교, 짧은 창의 편집 스크롤·팝오버 경계.
- 하네스 verify와 verify:app. Linux 화면 증거와 Windows Acrylic 실기 증거는 구분한다.

구현·검증 기록: [Forest Crystal 적용](../implementation/2026-11-10-forest-crystal.md).

## 0.6.2 시안 재대조·보정

0.6.1의 Linux 캡처는 시안보다 평평하고 불투명했다. 사용자가 원본 시안을 다시 올려 보정과 아이콘 교체를 요청했다.
root의 넓은 색 덮기를 줄이고, 테두리 반사·내부 유리 경계를 구분한다. 일정 막대는 불투명 색 혼합을 투명 혼합으로 변경하며 읽기 위한 얇은 반사층을 유지한다.
대표 P 아이콘은 업로드된 녹색 유리 타일과 흰색 P를 기준으로 재제작한다. 제목 표시줄·창·트레이·About·EXE·설치/제거에 같은 아이콘을 적용한다.
앱의 창/패널/본문 배치와 업무 기능은 유지한다. 시안의 예시 색상 때문에 저장된 프로젝트 색을 바꾸지 않는다.
라이트 본문 잉크는 가독성 보정을 위해 `#082C23`을 사용한다.
CSS 투과는 검정/흰색 테스트 배경을 실제로 합성한 픽셀 차이로 확인한다. 테스트 배경 캡처와 실제 Windows 바탕화면 투과 인수는 구분한다.
[보정 구현·검증](../implementation/2026-11-10-glass-correction.md)을 따른다.

## 0.6.3 행 밀도·알림 조작 보정

사용자가 보정 화면의 프로젝트·일정 행을 현재의 약 2/3로 줄이고 알림 입력을 스위치로 바꾸도록 요청했다.
프로젝트 행은 64→44px, 일정 행은 60→40px로 조정한다. 프로젝트 15px/700·일정 13px/400,
프로젝트 배경과 일정 들여쓰기는 유지하며 두 줄 이름/날짜가 행 안에 들어가도록 여백을 줄인다.
가상화 높이·행 위치·일정 막대 중심을 함께 맞춘다. 일정 추가·편집의 시작일/종료일 알림은 독립된 스위치다.
초기값·저장 버튼·알림 처리 규칙은 유지한다. [구현·검증](../implementation/2026-11-10-compact-rows.md)을 따른다.

## 0.6.4 Deep Gray / Steel Blue

사용자가 설치본의 두꺼운 rim·회색 모서리와 작은 아이콘을 지적하고, 딥 그레이 시안을 승인했다.
중립 실버 버튼은 밋밋하다는 피드백에 따라 스틸 블루 선택/저장/일정 추가 버튼 시안으로 확정했다.

- 창 바깥 radius는0, 배경은 창 끝까지 채운다. 두꺼운 반사층과 이중 경계를 제거하고 단일1px 경계만 둔다.
- 다크 바탕 `#202225`, 패널 `#2B2E31`, 기본 글자 `#F1F2F3`, 주요 조작 `#477FAE`와 옅은 파란 경계다.
  일반 버튼은 회색, 프로젝트별 막대 색은 저장된 값을 유지한다. 라이트 팔레트의 기존 가독성·기능은 유지한다.
- 사용자가 업로드한 `Planrail-appearance-settings.json`: 창 투명도58%, 패널44%, 버튼70%, 미리보기 흐림2px.
  다크 모드의 창/기본 패널/기본·선택 버튼 CSS 배경 alpha는 각각0.42/0.56/0.30이다. 글자·아이콘에는 opacity를 적용하지 않는다.
  패널/일반 버튼의 반사층은 별도 합성되므로 최종 픽셀 투과율과 배경 alpha는 다르다.
- 툴바·간트·달력·편집의 기본 패널은 같은 alpha, CSS blur2px. 팝오버·모달은 겹친 내용의 가독성을 위해
  별도 진한 표면과 기존 blur28px를 유지한다. 이 수치는 Windows Acrylic 자체의 흐림 강도를 바꾸는 설정이 아니다.
  앱에 새 투명도 설정 UI를 추가하는 범위는 아니다.
- 기존 P 형태를 유지하고 스틸 블루 타일·두꺼운 흰 선·작은 여백으로 재제작한다.
  Windows 창/트레이/EXE는16·24·32·48·64·256px ICO, 제목·About·알림·다른 OS는 PNG를 사용한다.
  작은 ICO 프레임은 작은 크기에 맞게 단순화한 동일 원본에서 개별 인코딩한다. Windows150% 배율의 실제 선명도는 별도 확인한다.

구현·검증: [0.6.4 기록](../implementation/2026-11-11-steel-blue.md).
