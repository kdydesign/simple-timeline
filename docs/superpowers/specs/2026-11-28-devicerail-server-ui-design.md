## 화면 선택

상태를 빠르게 읽고 같은 서버에서 SSH나 매크로를 열 수 있도록 **A 요약형**을 선택했다. B 실행형은 자주 쓰는 명령을 맨 위에서 찾기 쉽고, C 기록형은 실행 간 결과 비교에 유리하며, D 표형은 좁은 공간에 많은 속성을 담는다. 수정 A안에서는 SSH와 제품 서비스가 각각 무엇을 언제 관측했는지 카드 두 개로 보여준다. 명령의 실행 시각과 결과는 그 아래의 **매크로** 영역에서 읽는다.

목록에서는 처음 시안의 이름 왼쪽 별을 실제 토글로 쓴다. 장비별로 행에 있는 별은 이 한 개이고 오른쪽 도구는 **수정 · 삭제** 두 개다. 매크로 추가 창은 대상 서버를 먼저 보여 주는 시안으로 정했다.

## 서버 목록과 즐겨찾기

- DeviceRail 제목은 **서버 목록**이다. 등록·다시 검사, SSH와 제품 서비스 두 상태, 목록 하단 집계는 기존 기능을 사용한다.
- 첫 셀은 **별 토글 → 서버 이름 → 알림 종** 순서다. 별은 모든 행의 같은 자리에 둔다. 즐겨찾기면 노란 별, 해제 상태면 중립색의 빈 별이다. 알림을 켠 서버에만 PlanRail 일정의 활성 알림 종을 이름 바로 뒤에 표시한다. 종은 ‘장비 이상 알림 켜짐’을 안내한다.
- 마우스·Enter·Space로 별을 누르면 해당 서버의 즐겨찾기만 전환한다. 이름이나 행을 선택하면 오른쪽 상세가 열린다. 수정·삭제는 클릭한 행의 ID를 대상으로 기존 편집 창·삭제 확인 창을 열며, 행 선택 이벤트로 전파하지 않는다. 상세에서 제공하던 관리 동작도 같은 저장·삭제 경로를 사용한다.
- DeviceRail과 PostRail의 즐겨찾기 활성색은 같은 노란색을 사용한다. 별의 내부만 채우고 포커스 링은 일반 버튼 패턴을 따른다. 서버 이름과 동작이 포함된 접근 가능한 이름, `aria-pressed`, 툴팁으로 등록 여부를 확인할 수 있어야 한다. 빠른 연속 입력은 같은 저장을 중복 전송하지 않는다. 저장 실패 시 기존 선택값과 오류를 표시한다.
- Home 위젯 제목은 **서버 상태**다. DeviceRail과 같은 저장 스냅샷에서 즐겨찾기만 걸러 기존 장비 순서의 앞 **5대**를 표시한다. 숨겨진 여섯 번째 서버가 있으면 앞쪽 별을 해제했을 때 다섯 번째 자리를 채운다. 서버 이름은 호버 시 기존 링크 강조색·밑줄, 키보드 포커스 시 포커스 링을 사용한다. 이름을 누르면 같은 ID의 상세로 이동한다. **DeviceRail 열기**는 PostRail 위젯의 하단 링크와 같은 위치·스타일로 두며, 빈 위젯에서도 전체 목록에 접근할 수 있다.

## 등록·수정 창

| 대상 | 동작 |
| --- | --- |
| 장비 등록 창의 배경 | 배경을 클릭해도 창, 포커스 범위, 입력 초안을 유지한다. 취소·Escape 또는 저장 성공으로 닫는다. 저장 중에는 중복 제출을 막고, 저장 실패 시 초안과 오류를 표시한다. 배경 클릭 변경은 등록 창에 적용한다. |
| 위치 | 등록·수정 양쪽에서 입력란을 숨긴다. 새 장비는 기존 저장 형식의 빈 기본값을 쓰고, 기존 장비 수정 시 저장된 `location`을 그대로 전달한다. 이미 저장한 위치는 상세에서 보조 정보로 조회할 수 있다. |
| 제품 서비스 검사 | PlanRail 일정 추가의 **소속 프로젝트** 공용 Select를 사용한다. 트리거와 열린 옵션 목록, 키보드 탐색·선택·닫기를 함께 맞춘다. 미설정·HTTP(S) 상태 URL·TCP 포트 선택과 조건부 입력·검증은 그대로 적용한다. 열린 목록에서 첫 Escape는 목록을 닫고 포커스를 트리거로 돌린다. |
| 즐겨찾기 | 기존 ‘Home 즐겨찾기’ 체크박스를 **즐겨찾기** 레이블과 알림과 같은 Switch로 바꾼다. 알림과 즐겨찾기는 독립적인 초안 값이다. 저장 시 목록·상세·Home이 같은 값을 읽고, 취소 시 기존 값을 사용한다. |

## 수정 A안의 상세

수정 A안의 예시 배치다. 즐겨찾기에 등록한 서버는 이름 왼쪽에 노란 별, 알림을 켠 서버는 이름 오른쪽에 종을 표시한다.

```text
★ QA-03  🔔                                      [SSH 열기]
  10.0.0.23:22

 SSH                         제품 서비스
 ● 가능                      ● HTTP 503
 마지막 검사 14:32:08         마지막 검사 14:32:10

 매크로                                      [매크로 추가]
 버전 확인                                        [실행]
 ▾ 버전 확인   [성공]                             14:28:42
   대상 · 시작/종료 · 실행 결과 · 표준 출력 · 표준 오류
```

각 카드는 해당 항목의 `checkedAt`을 사용한다. 검사 대상과 마지막 성공 시각은 보조 정보로 읽을 수 있게 한다. 첫 검사 전에는 미확인, 제품 대상이 없으면 미설정으로 표시한다. 재검사 중에는 이전 값의 시각과 ‘검사 중’을 함께 보여주며 오래된 결과에는 기존 ‘오래됨’ 표시를 적용한다. 좁은 폭에서는 SSH·제품 서비스 순서로 카드를 쌓는다. 상태는 색과 텍스트를 함께 사용하고, 주소와 시각은 숫자를 읽기 쉽게 정렬한다.

아래 **매크로** 제목 오른쪽에는 매크로 추가, 각 행에는 이름과 **실행** 버튼을 둔다. **SSH 열기**와 **실행**은 장비 등록 버튼의 파란 글래스 패턴을 사용한다. SSH 열기는 기존 TermRail 진입점을, 매크로는 대상 확인·지문·인증을 포함한 기존 실행 경로를 사용한다. 같은 서버에 진행 중인 명령이 있으면 기존 실행 잠금을 적용한다.

### 결과와 펼침

요약 한 줄에 매크로 이름, 작은 결과 배지, 시각을 표시한다. 배지의 높이·외곽선·반투명 배경은 PlanRail 하단의 호스트·멤버 배지를 따른다. 성공은 초록, 실패는 빨강, 결과 확인 필요는 주의색으로 구분한다. 연결 중·호스트 키 확인·로그인 대기·실행 중·취소됨도 실제 상태 이름으로 표시한다. 배지는 상태를 읽는 요소이고 펼침은 요약 줄 전체로 조작한다.

선택한 서버의 결과 중 **가장 최근 한 건**을 자동으로 펼친다. 새 실행이 완료되면 성공과 실패 모두 출력까지 바로 보인다. 다른 기록은 요약 줄에서 수동으로 펼치고 접을 수 있다. 주기 검사나 같은 실행의 출력 갱신이 사용자가 접은 기록을 다시 열지 않도록 실행 ID로 구분한다. 완료된 요약의 시각은 종료 시각, 실행 중에는 시작 시각을 쓴다.

| 펼친 기록 | 성공 예 | SSH 연결·인증 실패 예 |
| --- | --- | --- |
| 대상 | QA-03 · `10.0.0.23:22` | 123123 · `127.0.0.1:12222` |
| 시각 | 시작 15:42:08 · 종료 15:42:10 | 시작 15:40:26 · 종료 15:40:26 |
| 결과 | 성공 · 종료 코드 0 | 실패 · SSH 연결 또는 인증에 실패했습니다. |
| 표준 출력 | `v24.22.3` | 출력 없음 |
| 표준 오류 | 출력 없음 | 출력 없음 |

서버 이름·주소는 실행 당시 값을 쓴다. 두 출력 영역을 각각 표시하고 줄바꿈, 부분 출력, 기존 잘림 안내를 보존한다. 명령 실행 후 실패면 실제 종료 코드나 종료 신호를 표시한다. SSH 연결·인증 단계에서 끝난 경우 숫자 종료 코드를 만들어 내지 않는다. 실행 도중 연결이 끊겨 종료를 확인할 수 없으면 **결과 확인 필요**와 수신한 출력을 보여준다. 서버 검사 결과로 명령의 성공 여부를 추정하지 않는다.

서버마다 **각 매크로의 마지막 실행 한 건**을 앱 메모리에 보관한다. 같은 서버에서 같은 매크로를 다시 시작하면 해당 기록을 새 실행으로 교체한다. 다른 매크로나 다른 서버의 기록은 각각 유지되며, 앱을 종료하면 실행 기록이 비워진다.

### 매크로 추가 팝업

기존 WorkRail 대화상자 크기와 글래스 재질을 따른다. 상단에 **매크로 추가** 제목과 닫기, 그 아래 하나의 읽기 전용 영역에 **대상 서버** 레이블, 강조한 서버명, 한 단계 낮은 강조의 `호스트:포트`를 둔다. IPv6 주소는 대괄호로 포트와 구분한다. 그 아래 **매크로 이름 → 셸 명령** 순서로 입력한다. 레이블과 입력란은 가깝게 두고 두 입력 그룹 사이만 구분한다. 명령은 여러 줄을 읽을 수 있는 고정폭 입력란으로, 취소·저장은 하단 우측에 둔다. 등록한 매크로를 저장한 뒤 실행은 상세의 실행 버튼에서 시작한다.

```text
매크로 추가                                          [×]
대상 서버  QA-03
           10.0.0.23:22

매크로 이름
[버전 확인                                             ]
셸 명령
[hostname                                              ]
[node --version                                        ]

                                        [취소]  [저장]
```

조작 시안은 예시 데이터로 별과 Home 목록의 연동을 보여준다. 제품 구현 때는 기존 UI·Electron 검사에서 위젯의 접근 가능한 이름을 ‘서버 상태’로 갱신하고, 저장 경로·시각·매크로 출력은 일회성 프로필로 검증한다. 이번 단계의 산출물은 설계와 시안이다.
