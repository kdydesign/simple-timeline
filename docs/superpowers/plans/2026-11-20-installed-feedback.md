# NodeRail·TermRail 설치본 개선 구현 계획

[설치본 피드백과 인수 기준](../../design/noderail-termrail-installed-feedback.md)

| 작업 | 변경 위치와 완료 기준 |
| --- | --- |
| Windows ZIP 진단 | `zip-install`, Windows 어댑터와 작업 이력에서 최초 실패와 정리 오류를 분리한다. 디렉터리 생성·권한 조회·최종 이동 실패와 다음 정상 설치를 재현한다. |
| 버전 목록과 메뉴 표시 | Node 버전 셀의 색과 의미를 연결한다. 접속 중 Home·PlanRail·NodeRail로 전환했을 때 터미널이 그려지지 않고 복귀 뒤 같은 세션이 계속되는지 확인한다. |
| 서버별 시작 파일 | 메인 프로세스의 파일 선택기와 사용자 보호 저장소를 사용한다. 신뢰 확인, SSH 인증 성공·실패, 원격 셸에서 시작 작업 종료 뒤에도 유지되는 상태를 일회성 서버로 검사한다. |
| 서버 편집 | 필드별 검증, 기존 프로필 수정, 파일 가져오기·제거·취소를 검사한다. 목록이나 레이아웃에 원문 비밀번호가 기록되지 않아야 한다. |
| 작업 탭 | 한 칸의 서버명, 분할 시 작업명·터미널 수, 이름 변경, 닫기, 저장·복원과 별도 창 복귀를 검사한다. |
| 통합 검증 | 내장 도움말과 사용자 가이드를 실제 레이블에 맞춘다. 저장소 하네스와 전체 앱 검사를 순차 실행하고, Windows 패키지와 Linux 실행의 결과를 구분해 기록한다. |
