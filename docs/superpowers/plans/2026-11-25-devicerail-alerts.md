# DeviceRail 장비 알림 구현 계획

[승인 설계](../specs/2026-11-25-devicerail-alerts-design.md)에 따라 1.2.0에서 구현한다. Electron 메인 프로세스에서 검사와 발송을 처리하며 React에는 장비별 선택값만 전달한다.

- [x] DeviceMonitor에서 장비별 검사 회차 완료를 전달한다. 겹치는 요청, 주소 교체·절전 취소, 다른 장비의 늦은 응답을 단위 테스트로 확인한다.
- [x] DeviceStore에서 기존 장비는 알림 꺼짐으로 읽고, 검사 항목별 장애 상태를 기억한다. 두 번 연속 실패·묶음 발송·복구·재시작·무음 해제를 일회성 DB로 검증한다.
- [x] 장비 등록·수정에 PlanRail 알림 스위치를 연결하고 저장·취소 동작을 검증한다. 알림 발송은 기존 Windows 발송기와 전체 무음 정책을 사용한다.
- [x] 도움말·릴리즈노트를 갱신하고 하네스 및 전체 앱 검사를 수행한다.
