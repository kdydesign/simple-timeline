# Home·PlanRail 준비와 Electron 메인 응답성 개선 계획

기준 커밋은 `3271e63`이다. [1차 승인 설계](../specs/2026-11-20-home-planrail-performance-design.md)와 [2차 측정](../../harness/electron-phase2-2026-11-20.md)을 기준으로 renderer, 메인 저장 경로, 보조 창을 각각 검증한다.

| 작업 | 구현과 검증 |
| --- | --- |
| 표시용 스냅샷 인덱스 공유 | App에서 현재 보이는 스냅샷당 한 번 계산한다. 단독 간트·달력, 필터, 드래그 중 공유 회수에서 정렬과 선택이 일치하는지 확인한다. 일정 3건·1만 건에서 Home 준비 및 첫 막대 편집을 전후 교대로 측정한다. |
| 저장과 재조회 중 메인 작업 축소 | 휴면 자료 쓰기 권한을 대상 일정 기준으로 검사한다. 로컬 알림 평가는 활성 역할에서 시작·종료 알림을 설정한 일정만 읽는다. 전체 조회는 정렬 및 권한 계약을 지키면서 반복 작업을 줄인다. 커밋·롤백·공유 회수 직후의 조회와 일회성 DB의 일정 한 건 저장을 확인한다. |
| 릴리즈노트의 메모리 회수 | 이번 선택에 따라 명시적으로 닫은 창을 해제한다. 메인에서 읽던 버전과 스크롤을 보관하고, 주 창이 트레이로 숨겨진 경우에만 기존 창을 함께 복원한다. 재열기·이전 창 이벤트·앱 종료를 검증하고 창이 차지하는 메모리를 전후 비교한다. |
| 인수 기록 | 각 실험의 원시값과 조건을 보관한다. 저장소 하네스와 앱 전체 검사를 실행한다. Linux의 실행 결과, Windows CI의 자동 검사, 실제 설치본 150% 배율 측정을 각각 기록한다. |

판단에 영향을 주는 조건은 날짜·권한 필터가 달라진 동안의 드래그, 저장 뒤 재조회 실패, 역할 전환 도중의 휴면 자료, 릴리즈노트 닫기 직후 다시 열기, 트레이 복원이다. 도움말은 사전 준비로 첫 열기에 이점이 있어 기존 정책을 유지한다.
