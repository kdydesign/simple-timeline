# NodeRail·Home 세부 개선 구현 계획

**목표** 승인한 패널 A·검색 D·Home 시안과 폴더·릴리스 동작을 제품에 반영하고 기존 Windows 빌드 실패를 함께 해결한다. [승인 설계](../../design/workrail-node-detail.md)

| 작업 | 코드와 경계 | 확인 기준 |
| --- | --- | --- |
| 환경 검사·NodeRail | useNodeManagement가 명시적 검사 수명을 관리한다. NodeScreen에서 배지·상단 진행선·입력 재질·고정 제목을 렌더한다. | 포커스 조회와 수동 검사 구분, 중복·실패·대상 교체, 다크/라이트 헤더와 실제 스크롤 |
| Home | Home에서 Node 작업의 이전 목록과 레이어, 종료일과 오늘의 달력 날짜 차이, 폴더 버튼을 표시한다. | 작업 중 입력 차단·복구·취소, 날짜 경계·공유/개인·좁은 화면 |
| 관리자 열기 | renderer는 현재 선택 ID만 전달한다. Main에서 유효한 관리자 루트·실행 중 WSL과 공식 릴리스 URL을 결정한다. | 타입·발신자 검사, 이전 환경/임의 경로 거절, opener 실패와 미설치 관리자 처리 |
| CI | footer의 참여자 표시 기준을 실제 가용 너비에서 재현한다. | 긴 이름·버전·알림 경계와 키보드 목록에 대한 회귀 검사 |
| 통합 | 일회성 프로필에서 전체 앱 검사, repository harness, 원격 Windows·Linux workflow와 설치/업데이트 artifact를 확인한다. | 실제 Windows 사용자 PC와 WSL 인수 범위를 자동 검사와 구분한다. |
