# 2026-11-11 목록·알림 간편 편집 구현 계획

사용자 Q1~Q5 답변과 최종 `진행해` 승인. 기준 HEAD 4fe66d0, main에서 요청 범위만 변경한다.

## 승인 범위

- X/Alt+F4 즉시 트레이, 실패 시에만 종료/취소. Exit의 저장 대기·미저장 확인 유지.
- 목록 휴지통으로 확인 없이 프로젝트와 일정 삭제. 멤버 공유 자료는 삭제 불가.
- 알림 켜진 일정 옆 아이콘 → 독립 팝업, N/시각/시작·종료/저장·취소. 자신의 알림만 저장. 변경 후 바깥 클릭/Escape/X/취소는 버리기 확인.
- 기존 미저장 편집이 있으면 목록 삭제·빠른 알림 편집 차단. 팝업 초안도 종료 보호에 포함.
- 높이890(work area 제한), 토글 애니메이션, 월 목록 clipping 수정, 공유명 오른쪽 배지.
- 목록 배경 rgb(255 255 255 / 5%), 프로젝트 팝업 rgba(43,46,49,.7)/blur10px, 팝업 X 아이콘만/hover 유지, 옅은 빨간 삭제 버튼, reminder-notice padding10px20px/margin-bottom0/background#effb3a1c, 간트 제목 아래선1px.
- 연결 오류 진단/문구 변경은 제외.

## 순서와 완료 조건

1. 알림 전용 저장 API: 실패하는 경계·DB 테스트 → main에서 현재 저장된 날짜로 검증, 알림 열만 갱신. 기존 member 저장 재사용. 스키마 변경 없음.
2. 목록 즉시 삭제·알림 팝업: UI 실패 테스트 → 권한/dirty/저장 중 보호, 필드 오류/결과 불명/삭제된 일정, 독립 ID와 포커스 복귀.
3. 닫기·높이·스타일·월 목록: 관련 회귀 검사 수정/추가 후 실제 Electron에서 팝업과 월 목록, 전환 확인. 일반 소규모 CSS 값은 별도 구현복제 테스트 대신 화면으로 확인.
4. 전체 verify:app·하네스·diff 검증, 독립 최종 코드 리뷰, 기존 문서 보정, main commit/push. Windows 실기는 별도 미검증.

## 통합 주의

알림 변경은 저장된 날짜 기준 검증하며 전체 편집기 초안·공유 원본의 이름/날짜를 덮지 않는다. 빠른 팝업은 저장 overlay의 자손으로 유지한다. 동기화로 삭제/회수되면 저장 차단. 기존 툴팁 범위 유지.

## 완료

구현·독립 리뷰 P2 보정·전체7단계 및 하네스 검증을 완료했다. [결과와 미검증 범위](../../implementation/2026-11-11-quick-actions.md)를 따른다. main 직접 commit/push는 기존 승인된 전달 방식이다.
