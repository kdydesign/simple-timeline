# DeviceRail 1차 구현 계획

[확정 설계](../../design/device-monitor.md)의 인수 시나리오를 기준으로 구현한다.

1. 메인 프로세스에 PC별 장비·매크로 저장, SSH 및 제품 서비스의 독립 검사와 트레이 주기를 연결한다. 일회성 서버로 결과·동시 검사·주소 변경을 검증한다.
2. 장비 한 대에서 명시적으로 시작한 SSH 매크로의 지문 확인, 로그인, 실행 결과와 연결 종료 처리를 검증한다. TermRail에는 저장·임시 프로필 분기와 레이아웃 등록을 연결한다.
3. 기존 글래스 패턴으로 A안 장비 표·상세 및 Home B안 위젯을 구현하고 실제 Electron에서 메뉴 이동, 등록, 즐겨찾기와 작업을 검증한다.
4. 버전·도움말·릴리즈노트와 설계 상태를 갱신한다. 하네스와 앱 전체 검사를 통과한 변경을 main에 반영하고, 해당 SHA의 GitHub Actions와 Windows 설치·업데이트·artifact를 확인한다.

진행 내역과 실제로 수행한 검사는 [1.2.0 구현 기록](../../implementation/2026-11-24-devicerail.md)에 남긴다.
