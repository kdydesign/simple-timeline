# PostRail 첫 버전 구현 계획

기준은 [최종 설계](../../design/postrail-workspace.md)와 [Q1~Q12 인수 기준](../../design/postrail.md)이다. 저장·전송·결과 조회는 메인 프로세스가 맡고 PostRail과 Home은 같은 실행 상태를 구독한다.

| 단위 | 구현 위치 | 확인할 결과 |
| --- | --- | --- |
| 요청·환경 저장 | shared/postrail, main/postrail/store | 프로필별 SQLite, 보호 저장 선택, 요청별 인덱스 원자적 예약, 복제·그룹 삭제·재시작 검증 |
| 실행·인증 | main/postrail/runner | 일회성 서버에서 순차 전송, 환경 토큰 재사용, 401·중지·시간 초과, 응답 및 임시 결과 페이지 확인 |
| 앱 통합 | main/bootstrap, main/postrail/ipc, preload, renderer/postrail/usePostRail | 주 창 전용 IPC, HTTP 평문 대상 확인, 공통 30초 대기 시간, 트레이 숨김과 종료 구분 |
| 편집·목록 | renderer/postrail | GET·POST·DELETE 편집·저장, 그룹·복제·단축키·환경 관리, 세로 편집기와 로그 확인 |
| Home·도움말 | renderer/workrail, shared/help | 최대 5개 즐겨찾기의 단건·반복 전송, 메뉴 전환·도움말 및 실제 화면 경로 확인 |

단위·화면 테스트 후 저장소 하네스와 전체 앱 검사를 실행한다. 앱 검사 artifact를 생성하는 명령은 순차 실행한다.
