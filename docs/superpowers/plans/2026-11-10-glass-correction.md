# Forest Crystal 시안 재대조·보정

기준: `4802f1a`, 사용자 재업로드 라이트 일정 추가·다크·프로젝트 목록 시안.
승인된 디자인의 보정과 P 아이콘 변경 요청이 구현 범위다. 기능·날짜·공유·알림은 변경하지 않는다.

## 설계와 비교

0.6.1은 root 색과 패널 색이 겹쳐 평평해졌고, 막대는 불투명 색끼리 혼합됐다.
시안의 밝은 유리 테두리, 투과되는 표면, 채도 있는 막대를 반영한다.
대표색 forest #075E54, emerald #00AC87, jade #B2E0CC, pearl #ECFFF8, ink #082C23, smoke #0C2B23.
기존 한글 시스템 글꼴·프로젝트 15px/일정 13px·C안 배치·18px 간격을 유지한다.
본문과 툴바의 동일 재질, 입력 가독성, 낮은 버튼 돌출을 유지한다.
앱 아이콘은 시안의 흰색 P와 녹색 유리 타일로 재제작해 제목 표시줄·트레이·About·EXE·설치/제거에 연결한다.

## 판단·검증 경계

Ruling: 재업로드된 승인 시안과 수정 요청으로 진행하며 다시 설계 승인을 묻지 않는다.
Ruling: 시안의 가상의 색상별 일정·삭제 버튼 위치·생략된 날짜 등은 기능 변경 근거로 사용하지 않는다.
