# Planrail Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans task-by-task. Checkboxes track execution.

**Goal:** 승인된 Planrail 개선을 기존 데이터·일정 기능을 유지하며 구현한다.
**Architecture:** Electron main은 트레이와 실제 종료 의도를 소유한다. renderer의 단일 선택 날짜와 가변 day width를 기존 날짜 도메인·가상화에 연결한다. shadcn/Radix 공통 컴포넌트는 도메인 계산과 분리한다.
**Tech Stack:** Electron / React / TypeScript / SQLite / Vite + shadcn/ui, Radix, Tailwind.
**Spec:** [승인 설계](../../design/planrail-improvements.md). 사용자의 2026-11-05 구현 지시가 최종 승인이다.

## Global Constraints

- 사용자에게 보이는 이름은 Planrail, 버전은 0.3.0. 내부 `simple-timeline`, `com.kdydesign.simpletimeline`, `%APPDATA%\\SimpleTimeline`, `simple-timeline.preferences.v1`은 유지한다.
- 날짜는 시간대 없는 YYYY-MM-DD, 0001~9999년, 양끝 포함. renderer의 Node·파일·DB 권한은 늘리지 않는다.
- C안 배치·290×442px 프로젝트 팝오버·오른쪽 편집 패널을 유지하며 A Zinc 토큰을 적용한다.
- 테스트는 임시 프로필만 사용하며 Electron sandbox를 끄지 않는다. 빌드·전체 검사를 겹쳐 실행하지 않는다.
- main 직접 커밋·push는 기존 상시 승인에 따른다. 기존 MVP 완료 단계는 다시 열지 않는다.

## Review Focus

- 숨긴 창의 저장/확인/앱 종료 경합: 실제 종료만 저장 대기와 확인을 수행하고 취소하면 접근 가능한 창을 남긴다.
- 0001/9999년 및 끝 날짜 왼쪽 배치: 후행 빈 공간에 가짜 날짜를 만들지 않는다.
- 최소 배율에서 1일 일정: 이동과 양끝 리사이즈가 구분되고 Space 패닝 뒤 클릭이 생성되지 않는다.
- 편집 오버레이의 중첩 팝오버: 포털의 포커스·Escape·외부 클릭이 입력을 잃게 하지 않는다.
- 실제 구버전 설치 업그레이드: 이름/실행 파일 변경에도 DB·설정·바로가기·설치 위치 연속성을 유지한다.
