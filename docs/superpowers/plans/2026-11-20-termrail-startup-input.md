# TermRail 기본 셸과 서버 수정 창 구현 계획

[승인 설계](../../design/termrail-startup-input-and-server-edit.md)에 따라 기존 서버 프로필과 파일 참조를 그대로 읽는다. SSH 입력은 해당 터미널의 메인 프로세스 세션에서 관리한다.

1. 일회성 SSH 서버에서 헤더만 있는 파일, 명령이 있는 파일, 복원한 세션을 검사한다. 기존 Bash 실행 요청에 의존한 검사도 기본 셸 요청과 실제 터미널 입력 검증으로 바꾼다.
2. SSH 인증과 셸 열기를 구분하고 수동 로그인과 같은 PTY를 연다. 출력에서 첫 프롬프트와 다음 프롬프트를 확인한다. 미확인·사용자 개입·종료 시 남은 입력을 취소한다. 일반 출력·분할 수신·추가 질문에 대한 회귀 검사를 둔다.
3. 터미널에 현재 대기 단계를 표시하고, 입력이 가능해지면 직접 타이핑할 수 있게 한다. 서버 수정 폼에는 추가 폼의 표준 팝업 스타일을 적용하고 편집 취소 및 크기를 검사한다.
4. 시작 파일 사용법과 업데이트 안내, 지침의 설계 링크를 갱신한다. 저장소 하네스와 앱 전체 검사를 순차 실행하고 검증한 변경을 main에 반영한다.
